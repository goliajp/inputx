# modern_vocab Phase 2 audit rubric — 2/3/4 字条目(宁缺毋滥,burden of proof 在 KEEP 侧)

背景:IME 拼音词库 overlay 被 dogfood 新闻语料灌水。freq=30000 的行绝大多数是「为了让某篇文章打字测试 PASS」被机械加进来的 jieba 切片,不是经过人工判断的词条。freq≠30000/300 的行是更早人工 curated 的,多数真,但同样要审。

审计问题只有一个:**这是不是一个真实、固定、词典意义上的中文词?一个 typer 会把它当一个词一次性打出来吗?**
拿不准 → DELETE(用户拍板:宁缺毋滥)。

每行格式:`pinyin\tword\tfreq\tlibflag`。libflag=`lib` 表示该词已在主词库 library.tsv 里(删掉本行只是去掉 30000 灌水,词还在);libflag=`-` 表示删掉本行该词从词库彻底消失。**libflag 只影响你对 borderline 的谨慎度:`-` 且你认为是真词 → keep;`lib` 且 borderline → 放心 delete(主词库兜底)。**

## DELETE 类别
- `frag-grammar` — 带语法功能词的切片:之态、之庙、拖着、听得、理论上、短期内、那一款、拉一把、认不认可(A不A)、奥运会后(+后/内/中/下)、在某种程度
- `frag-num` — 数字/量词拼装:八条、一万台、四五百、第二大、十九首
- `frag-np` — 拼装偏正/动宾短语,非词化:穿着衣物、更有滋味、表现出色、稳面积、整县制、安心用房、实际离岛、意向成交额。注意:已词化的偏正结构是真词要 keep(打工人、团年饭、烂尾楼)
- `frag-verb` — 动补/动趋残片:吊走、拆掉、写信给、涨上去
- `name-person` — 新闻人物/非名人姓名:范铭升、潘志琛、赖德湘、侯炳莹、李默庵、壮一郎。名人/历史人物/虚构名角色 keep(孙悟空、明成祖、李白、鲁迅)
- `name-obscure` — 小众音译/日文名/地名碎片:格平根、塔提、温菲尔德、神乐米、水村枫、是泽村、汇德
- `org-local` — 地方小机构/公司/楼盘/街道:万石楼、首开?(判断:全国知名企业 keep)
- `title-slice` — 作品名切片/衍生:舌尖上(舌尖上的中国切片)、茉莉花影
- `admin-wrong` — 错误/过时行政区划拼装:广西省(广西是自治区)。真实存在的县市区名 keep(增城、盈江、山海关区)
- `jargon-slice` — 行业黑话/统计口径碎片:社均、环比价?(环比是真词 keep;社均不是词)
- `stale-300` — freq=300 的历史降权残片按同标准审,多数 delete

## KEEP 类别(必须能说出它是真词)
- `word` — 词典/日常真词:快递、划水、地质、坑农、差饷、鸫科、率队、服役期、通透性、低噪音、模拟机、油烟味?(borderline:油烟味 lib 则删、- 则可 keep)
- `idiom` — 成语/熟语:残缺不全、鹿死谁手
- `name-famous` — 名人/历史/虚构知名人物:孙悟空、明成祖、麦克斯韦
- `geo-real` — 真实地名(国内县级以上、国外知名):多哈、增城、盈江、中南海
- `brand-known` — 全国知名品牌/机构/媒体:特斯拉、蚂蚁金服、纽约时报、微博
- `term-modern` — 现代词化术语/职业:产品经理、打工人、意大利语、西气东输(国家工程专名)、多动障碍
- `proper-histfic` — 知名典籍/历史专名:中华民国、弥生(时代)、能剧

## 硬规则
- 单字+功能词(之X、X着、X了)无条件 delete
- 词典真词但极冷僻(古语、生僻科名)且 libflag=lib → delete(主词库有,不需要 30000 灌水);libflag=- → keep
- 全国知名度是 name/brand/geo 的分界:省内知名 → delete

## 输出格式(TSV,无表头,必须覆盖分给你的每一行,不许跳行不许合并)
pinyin\tword\tverdict(keep|delete)\tcategory\treason(≤12字)
