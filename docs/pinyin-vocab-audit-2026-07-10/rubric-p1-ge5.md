# modern_vocab audit rubric (宁缺毋滥 — burden of proof 在 KEEP 侧)

背景:IME 拼音词库 overlay 被 dogfood 新闻语料灌水,大量「文章切片」被当词条收录。
审计问题只有一个:**一个中文 typer 会不会把这个字串当作一个固定词条一次性连打出来?**
拿不准 → DELETE。这是用户拍板的项目方向(宁缺毋滥)。

## DELETE(类别代码)
- `frag-clause` — 句子/动宾/介宾/状中切片:在此基础上、从去年至今、围着表格转、最忆是杭州、真正意义上、听得可开心
- `frag-coord` — 「X和Y / X与Y」并列拼装:支持和扶持、引导和培训、创新与创业、历史与未来
- `frag-np` — 拼装名词短语,非词化:客流小高峰、年轻消费群体、党建工作机制、政务服务窗口、快递包装治理工作、意向成交额
- `poem-line` — 诗词句切片:水光潋滟晴方好、才下眉头却上心头、为赋新词强说愁、苟利国家生死以、忽如一夜春风来
- `slogan` — 政治口号/宣传语/公文套语:以人民为中心、新发展理念、向真向善向美向上、打铁必须自身硬、全面建成小康社会、一厂一所一校一院
- `doc-title` — 文件/法条/报告标题:关于…的通知/意见、《…条例》、…发展统计公报、…行动计划
- `legal-num` — 法条编号/纯数字串:第一百七十六条、一百七十六、二百二十五
- `org-local` — 地方性/小众机构、公司全称、街道、楼盘、酒店、地方报社:宁夏晓鸣农牧股份有限公司、赤龙南街道、珠山区政协、湍口众安氡温泉度假酒店、瓷都晚报社
- `event-niche` — 小众赛事/展览/活动名:中国姿态雕塑大展、全国青年美展、蓬安放牛节
- `admin-suffix` — 「地名+市/县/区/镇/旗」拼装形(裸地名已足够,组合交给引擎):鄂尔多斯市、吉木萨尔县、湖州德清县、河南省安阳市
- `bad-pinyin` — 拼音本身错的行(如 sietelubu→列支敦士登、maxiaodajiajiakasi→马达加斯加):无条件 DELETE
- `sport-assembled` — 拼装赛事项目名:女子单人滑短节目、男子个人标准台资格赛、短道速滑混合团体接力决赛

## KEEP(必须能落进以下类别之一,否则删)
- `geo-world` — 国家、世界名城、著名地理实体:印度尼西亚、伊斯坦布尔、布宜诺斯艾利斯、珠穆朗玛峰、密西西比河、马六甲海峡、拉斯维加斯
- `geo-cn` — 中国省级行政区全称、全国知名地名/地理实体:新疆维吾尔自治区、内蒙古自治区、塔里木盆地、库布其沙漠、腾格里沙漠、京杭大运河
- `inst-national` — 国家级机构/政党/部委/央行/奥委会:中国共产党、中华人民共和国、中国人民银行、国家统计局、生态环境部、交通运输部、国际奥委会、中国社会科学院
- `edu-major` — 全国知名高校、世界名校:北京师范大学、中国人民大学、华中科技大学、爱丁堡大学
- `landmark-culture` — 全国知名文化地标/国宝/著名 IP/名企:人民大会堂、清明上河图、敦煌莫高窟、承德避暑山庄、泰坦尼克号、樱桃小丸子、唐人街探案、摩根士丹利
- `lexical-term` — 已词化的现代术语/职业:大语言模型、自由式滑雪、年化收益率、前端工程师、最后一公里、战略性新兴产业
- `proverb-national` — 国民级完整谚语(极少数,整句一次性打出的那种):路遥知马力、读书破万卷、神农尝百草。诗词名句不算(归 poem-line 删)

## 特殊
- freq=300 的行是历史上被降权未删的残片 → 用同样标准审,绝大多数应 DELETE
- freq 非 30000/300 的行是 dogfood 之前人工 curated 的 → 同样审,但多数是真词(注意 bad-pinyin 例外)
- 中国特色社会主义(zhongguotesesehuizhuyi)拼音少个 h → verdict 写 `fix-pinyin`,category `lexical-term`,reason 里给正确拼音 zhongguoteseshehuizhuyi
- 书名/典籍如 神农本草经、伤寒杂病论、送东阳马生序:全国知名典籍 KEEP(landmark-culture);小众书名 DELETE

## 输出格式(每行一条,TSV,必须覆盖分给你的每一行,不许跳行)
pinyin\tword\tverdict(keep|delete|fix-pinyin)\tcategory\treason(≤15字)
