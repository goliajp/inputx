吴钊燮

吴钊燮（xiè）（1954年10月31日—），中华民国政治人物、学者和资深外交官，民主进步党籍，彰化县大城乡人。现任国家安全会议秘书长、总统府全社会防卫韧性委员会副召集人，曾任外交部部长、总统府秘书长、副秘书长、国安会秘书长（第15任）、民主进步党秘书长、驻美代表、行政院大陆委员会主任委员、国立政治大学国际关系研究中心副主任等职务。


== 早年 ==

吴钊燮曾就读台湾省立台中第一高级中学；1978年毕业于国立政治大学政治学系；1982年取得美国密苏里大学政治学硕士；1989年取得俄亥俄州立大学政治学博士。35岁时返回台湾，在母校国立政治大学国际关系研究中心担任研究员，并兼任该校选举研究中心及政治学系教研职务；1999年至2002年担任国关中心副主任，在马政府时期也曾返回国关中心担任研究员。


== 政治生涯 ==


=== 陈水扁政府时期 ===
2002年，吴钊燮获陈水扁主政下的执政党政府任命为总统府副秘书长。
2004年5月20日卸任总统府副秘书长后，被任命为行政院大陆委员会主任委员。
2007年4月10日，接任中华民国驻美国代表，成为首位民主进步党籍驻美代表。在吴莅任后不久，即在双橡园创下一晚同时宴请马绍尔群岛、帛琉、基里巴斯和诺鲁等四位大洋洲国家总统的纪录，其后也曾在双橡园宴请萨尔瓦多总统埃利亚斯·安东尼奥·萨卡及随行要员。
2008年，民进党在总统选举中败北。8月4日吴钊燮自驻美代表处离任，返回政大国关中心担任约聘研究员。


=== 民进党在野时期 ===

2012年，苏贞昌当选民主进步党主席，吴钊燮获邀出任政策委员会执行长，同年底兼任民进党驻美代表。
2014年，蔡英文回任民进党主席，同年5月28日吴钊燮获邀担任党秘书长兼任驻该党美代表。


=== 蔡英文政府时期 ===
2016年5月20日，蔡英文主政下的民进党政府正式上任后，吴钊燮被任命为国家安全会议秘书长。
2017年5月18日，总统府发布人事异动，吴钊燮转任总统府秘书长。


==== 外交部部长 ====

2018年2月23日，行政院发布人事异动，吴钊燮转任外交部部长，2月26日到任。
外交部部长任内，中华民国陆续与多明尼加、布吉纳法索、萨尔瓦多、所罗门群岛、基里巴斯、尼加拉瓜、洪都拉斯、诺鲁等八国断交，是解严以后历任外交部长中断交国数量最多的，故被在野党中国国民党批评为「断交部长」。
2021年7月20日，吴钊燮宣布将在立陶宛首都维尔纽斯设立驻立陶宛台湾代表处，该年11月18日，驻立陶宛台湾代表处正式挂牌设立。该外交机构为欧洲第一个以「台湾」名义设立的代表机构，中华人民共和国外交部为此于8月10日召回驻立陶宛大使，11月26日再将驻立陶宛大使馆降级为代办处。
2022年8月2日至8月3日，时任美国众议院议长的南西·裴洛西率团访问台湾，是美国与中华民国断交以来首位访台的美国执政党籍国会议长。
2023年2月22日，吴钊燮与国安会秘书长顾立雄出现在美国在台协会华盛顿总部，并与美国副国务卿温迪·谢尔曼等官员对谈，是台美断交以来首位外长首次踏入华府。


=== 赖清德政府时期 ===
2024年5月20日，新任中华民国总统赖清德签署就任后第一份人事命令，吴钊燮回任国家安全会议秘书长。


== 政策与立场 ==
2012年10月30日，吴钊燮承认，过去民进党对于转型正义处理方式，常常只把转型正义当成选举工具，让支持者丧失信心，所以现在必须分门别类去处理、纠正过去的错误。
2021年4月28日，吴钊燮在接受英国天空电视台访问时说道，中华人民共和国似乎准备对台湾发动「终极一战」，他认为「台湾身处中国威权秩序扩张的最前线，解放军如果武力攻台，将对全球带来颠覆性的影响。」
吴钊燮几度接受BBC专访，2022年佩洛西访台时，在中国大陆批评其为台独的情况下，他则是表态，此趟行程目的其实主要是唤醒国际对台湾民主化的重视，他并承认两岸有历史问题：「我们希望维持现状。台湾对中国大陆没有管辖权，中华人民共和国对台湾也没有管辖权。这就是现实。」，他警告大陆「扩张主义」，并以克里米亚举例，一再容忍造成更大的风险，将是鼓励战争的错误道路上越走越远，以及提及了对选举与事实的不尊重等。
2023年11月3日，泰国公共电视台播出「台湾外长评估中国武统台湾之发展趋势」。吴钊燮称正如总统蔡英文在最后一次国庆日演说所说，现在两岸唯一的选项是和平，中华民国避免成为挑起冲突的一方，而目前台海战事并非迫在眉睫，也非不可避免，并表示愿在对等及尊严之前提下进行两岸对话。11日中国驻泰国大使馆与环球时报发文指称是台独分子、滥用言论自由等，引得吴透过社群平台X反讽该描述观点「太有趣了」，对采访节目的批评「令人难以置信」，《Thai Enquirer》商业主编艾利奇评论，公视是泰政府资助的单位，基于外交立场可以撤下，但中方无端指责泰国，使用粗暴的主张只会适得其反。


== 评价 ==
《中国时报》长年驻美的特派员傅建中对吴钊燮评论颇佳；「抛开他的意识形态不谈，他对美国事物的熟悉，英语表达的能力，都是上乘的，加上锲而不舍的执著与努力，实在是位称职的代表。」

== 争议 ==
2015年6月3日，TVBS新闻独家报导，蔡英文秘密拜访美国贸易代表署，蔡英文与立法委员萧美琴看到记者时脸色难看，吴钊燮一度伸手阻挡记者拍摄。
2016年8月30日，其叔父吴澧培接受台北之音访问时批评，「行政院院长林全与外交部部长李大维不适任，总统蔡英文不能再用林全，『林全不下台，蔡英文没有明天』」；他曾和侄子吴钊燮说李大维不适任外交部部长，可是吴钊燮却为李大维辩护「除了我本人，他是最适合的人」，因为吴钊燮不认为民进党有人适任外交部部长，之后他就和吴钊燮「完全不讲话了」。
2019年1月14日，吴钊燮接受郑弘仪等专访，对赵怡翔赴美的派任表示力挺，并希望给年轻人一个机会。在中国时报报导中，指出过去吴钊燮担任民主进步党政策会执行长时曾表示，台美关系颇为复杂，包含政治、经济、文化等不同层面，亦必须面对美国行政、国会部门以及侨界等，如果完全没有这方面经验是相当令人担心的。其相关言论被认为立场不一。


== 个人生活 ==


=== 家庭 ===
吴钊燮之父为吴温培，叔父为吴澧培（美国银行家）是有名的台独大老。而二叔吴澍培是著名的统派人物，1948年申请加入中国共产党，1949年宣誓入党。该辈各兄弟成就不小，均在政府与商业有影响力。
其子吴廸为台湾人公共事务会政策协调员、民进党驻美办公室副主任。
