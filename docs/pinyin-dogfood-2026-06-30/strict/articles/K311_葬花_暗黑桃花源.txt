葬花·暗黑桃花源

《葬花·暗黑桃花源》，简称《葬花》，是中国大陆电子游戏开发组零创游戏开发的带有恐怖元素的恋爱冒险游戏，于2021年10月22日在Steam发行。作品改编自游戏制作人嵇零在2016年创作的漫画《桃花源》，讲述一个失意青年误入「桃花源」的奇妙遭遇。本作是零创游戏的第一部作品，游戏于2022年4月14日登陆iOS和安卓平台。


== 游戏系统 ==
《葬花·暗黑桃花源》采取恋爱冒险的游玩方式，玩家所扮演的角色是纪明。玩家游玩时，需要阅览屏幕上所显示的文本以了解故事情节和人物之间的对话，这些文字会与人物的立绘和背景一同出现，用于表示对话的对象。对话对象的立绘会随著对话进行而变化，根据对话的内容做出不同动作或表情，如脸红，惊愕，皱眉等。在部分场景中会遇见代替背景和人物立绘的电脑图像。游戏中会在预设的段落中出现行为选项供玩家选择，下一段文本在做出选择前并不能够显示。由玩家来决定主角接下来的行动，继而影响接下来的剧情发展，选项会导致不同的结局。游戏中有名为「思绪整理」的剧情树，方便玩家回顾自己完成了哪一些剧情支线，玩家可能透过剧情树切换到游戏中的任一章节。游戏中郑氏、大牛和村长三个角色存在好感度系统，角色好感度足够高才能开启相关剧情线路。在完成所有支线之后，游戏才会开启隐藏结局「葬花」的线路。游戏追加下载内容《折镜之蝶》，在故事初期玩家以严玥秋的视觉进行游戏，后半段会改回纪明的视觉。


== 故事简介 ==
本篇
一名私家侦探接到一起离家出走的失踪案件，调查发现失踪者似乎去寻找网路上流传的「桃花源」。侦探数次遁入山林寻觅未果，在分析当地失踪人士和去过「桃花源」的人的特征后，他猜测只有失意落魄之人才能进入「桃花源」。于是在催眠师朋友的帮助下，侦探伪造了一段失恋失业的记忆，化名纪明进入山林并准备了一个钟表在24小时后解除催眠。这次他成功进入了「桃花源」，在入口处遇到在此地尊为「神女」的双花，在双花的欢迎下，纪明和村民一同用膳畅谈。黄昏之际，村长告诫纪明入夜之后不要外出，夜间有「山鬼」徘徊，免得丢了性命。当晚纪明在好奇之下还是外出了，在村庄边的星空湖遇到了服饰和气质完全不同的双花。之后的数日纪明慢慢习惯「桃花源」的生活，白昼时纪明和村民交往，帮忙做农活，夜晚到星空湖与双花（夜）私会，讲述外界的风土人情。一日，钟表倒计时结束，恢复侦探记忆的纪明发现「桃花源」的时间和外界不同等种种诡异之处，同时他也马上锁定了可能是失踪者的村民青禾。是夜，他去拜访青禾，期间发现性情大变的村民，由此他推断村民入夜就会变成「山鬼」。
之后根据玩家的选择，纪明会选择信任郑氏、大牛、村长或双花其中一人，并在白天寻求的帮助或者选择独自一人策划逃离。在不同路线中，纪明都会得知「桃花源」背后的故事。战国时期的呼钺国拥有天外陨石名「长生石」能确保人死后灵魂寄宿其中永生不灭，秦始皇得知后索要此石不果与呼钺国爆发战争，呼钺国自知不敌，于是将天外陨石炼成丹药，令技巧师建墓穴，让公主「花」服下丹药与九百国民进驻墓穴，他们将会在「长生石」中延续呼钺国。公主「花」是整个「桃花源」的构建者，呼钺国民在「长生石」不会死去，经历千年之后，国民开始厌倦一成不变的日子，秩序崩坏，部分人沉迷纵欲，部分人沉迷杀戮，部分人变得自暴自弃。公主「花」不愿混乱持续，于是划分了昼夜的秩序，昼时村民只有最开始的记忆，包括她自己，每一年重置，国民一如最初的其乐融融，夜时恢复所有记忆，自由活动。被「长生石」吸引的人会进入「桃花源」，接近「长生石」的他们只有七天寿命，部分人得知真相后精神崩溃或者逃离期间被杀，在「桃花源」中变成了动物；部分人适应了「桃花源」的生活，可以选择抹去外面记忆成为村民，或者熬过七天后肉体的死亡考验，保留外面的记忆成为村民。
在完成所有路线后，玩家会回到故事的最初，也许是纪明使用取巧的手段进入「桃花源」，他获得了不同路线中的所有记忆，他决定和双花（夜）商讨，终结这个「桃花源」，让村民安息。纪明以轮回的记忆说服了所有村民，也获得双花（夜）的支持。纪明在回到现实之后把「长生石」带出墓穴，由于不忍心让村民魂飞魄散，他服下了「长生石」希望找到更好的方法。尽管在最后的七天纪明找不到其他方法，不过村民也随著纪明的步伐在最后几天看到翻天覆地改变的外界。

追加下载内容「折镜之蝶」
故事以失踪案件目标人物「严玥秋」角度展开，严玥秋由于校园霸凌和与父亲的冲突，和网上认识的青禾离家出走，并打算去寻找桃花源。两人寻得「桃花源」，在察觉该地的异样而逃离期间被抓。玥秋决意赴死，不愿成为村民，双花怜悯其女子身份，将其囚于房内，待七日后灵魂消散。囚困期间，玥秋可以选择是否用手上卫星电话求救，不求救为本篇故事剧情，选择求救会加快侦探的行动计划。侦探将解除催眠的钟表设置为12小时，让他能即时救下即将消散的玥秋。成功逃离桃花源，侦探会发现玥秋似乎进入了青禾的身体中。侦探与委托人交流得知，玥秋存在人格分裂，只是在「桃花源」的两人同时存在的经历让侦探半信半疑。侦探可以选择不深究玥秋的情况，在半年后会收到玥秋跳楼自杀的消息。反之，侦探会选择帮助玥秋，以依附理论为借口，迫使委托人妥协，让两人可以定期相聚，玥秋也能在两人独处时，不再隐藏自己。


== 登场角色 ==
纪明
故事主人公，本职为侦探，为了调查失踪者，使用了取巧的手段进入「桃花源」。向往「桃花源」的简单纯朴生活，在不断轮回中产生了帮助村民摆脱永生的念头。
双花（声：Hanser）
女主角，战国时呼钺国的公主，构建「桃花源」的核心，在「桃花源」中呼钺村的神女，指定了昼夜的规则。昼时性格温柔善良，维护村中的秩序，入夜时性格清冷高贵。对外面世界充满向往。
青禾（声：蔡书瑾）
误入「桃花源」的少女，纪明调查失踪案件的关联人物。本来于好友一同进入「桃花源」，在发现夜晚秩序崩溃的呼钺村后，逃亡期间好友为保护她而离世。纪明发现她时，已经有些神志不清。真实身份是严玥秋过去养父母早夭的女儿，由于养父母的招魂仪式，进入严玥秋体内。
严玥秋（声：蔡书瑾）
失踪案件目标人物，上市公司老板的女儿，年幼丧母，三岁时被拐卖到农村。数年后警方严打拐卖事件，在一次行动中救出了玥秋，并帮助她找回亲生父亲。那时父亲另建家庭，事业有成，玥秋的回归被他认识是不光鲜的事情，他为玥秋提供了优厚的生活条件，但是对玥秋不甚关心，聚少离多。拐卖时的养父母，一直把她当作早夭的女儿，并对其进行招魂仪式，故体内有另一个的灵魂。玥秋由于拐卖的经历，性格较为孤僻，长大后意识到另一个灵魂的存在，并与其沟通，亲父视她有精神问题，对其实施治疗。校园霸凌之后，玥秋出现记忆错乱等情况，视另一个灵魂为网上认识的网友。
郑如愿（声：朱婧）
呼钺村中的寡妇，本为呼钺国一将军之女，丈夫在对秦作战时战死。昼时是村内织布的好手，入夜时是刀法出众的独行者。
村长（声：巫蛊悠悠）
呼钺村村长，是村中最年长者。本为呼钺国逃兵混进了「桃花源」的队伍中，一直十分内疚自责，导致性格扭曲。昼时是村内德高望重的老人，入夜时是喜欢杀戮外来者的狂人。
大牛（声：魏一凡）
呼钺村的猎户，本为呼钺国公主的亲卫，千年时间让他失去生的意志，入夜时自暴自弃在家中独处。
小石头（声：柳知萧）
郑如愿的义子，本为如愿丈夫之弟。昼时是村内的熊孩子，入夜时是村内的孩子王。


== 开发 ==
游戏制作人嵇零是零创世动漫公司的创始人，过去有负责过一些漫画剧本，2020年嵇零拍摄的短片电影《玻璃糖》获得美国电影节提名，原计划在电影方面发展，受到2019冠状病毒病暴发影响，电影业大受影响。疫情让嵇零在家中待了一个月，期间玩了YUZUSOFT的恋爱游戏《千恋＊万花》从而萌生了创造文字冒险游戏的想法。游戏在初期企划中名为《桃花源·枯骨葬花》，故事改编自嵇零在2016年创作的漫画《桃花源》，当年受限漫画杂志篇幅，漫画只有96页，有很多故事细节无法表达，一直是嵇零的遗憾，所以选择重写整个故事。《桃花源》和《葬花》主题设计灵感是源于2005年电影《神话》，女主角的形象参考电影中的「玉漱公主」，而作品的世界观设计有参考《暮蝉悲鸣时》《千与千寻》和《沙耶之歌》的个别设定。嵇零在2020年5月完成游戏的专案计划书后就前往成都和制作过文字冒险游戏的游戏制作人交流经验，7月他从广州的朋友凶真获得第一批投资，同时在广州创建零创游戏公司，然后嵇零前往成都组建游戏制作团队，初期团队有四人。成员是嵇零透过招聘软件招募的，期间有人离开，最终开发团队共五人。
在角色设计方面，女主角双花相较漫画《桃花源》的小桃花设定更为丰富，角色有昼夜两种设计，嵇零曾找过五位画师进行设计，最后选用了慢慢的设计。配合故事背景，村民是自秦朝就与世隔绝，角色的服饰设计主要参考秦国时期的服饰，画师慢慢在设计时有特意参考文献资料。慢慢本身为程序专业，绘画是自身爱好，过去主要是画萌系画风，角色夜晚的设计给与她很多的挑战，让她走出舒适区，尝试了更多的创作。在制作后期，画师叉子加入负责配角的电脑图像创作。游戏的场景美术全部由fronzenX负责，fronzenX和嵇零透出创作主题场景「桃花源·俯瞰景」确立作品的氛围和美术风格，之后的场景创作遵循两个原则，一是符合陶渊明《桃花源记》中的描述，二是。
游戏的演出由嵇零负责，过去他在电影和漫画创作的经验，让他能熟练地透过运镜、配乐等方式在游戏中呈现他想要的效果。程序方面主要是薪魂负责，游戏使用Unity引擎开发，主体框架使用UTAGE，基本是通过Excel表格配置游戏流程中的图文表现，辅以小插件制作的各种镜头效果，完成开发。在音乐方面，最初是找《泡沫冬景》的制作组Nekoday工作室负责，Nekoday的乐师完成其中三首配乐。之后的其中一首《呼钺之舞》外包给了锐力音乐制作，剩下的由Candy_wind负责。Candy_wind本身是程序员，没有接受过专业的音乐培训，他利用自己的专业知识开发了一款人工智能作曲软件Antinomi辅助作曲。《葬花》是他第一次负责游戏的配乐。
游戏的剧本由嵇零创作，嵇零在创作剧情期间会听音乐获得灵感，包括《神话》《千恋＊万花》《美少女万华镜5》《天穗之咲稻姬》《新白娘子传奇》的音乐。游戏中有不少重复的剧情，嵇零希望由此塑造出一种永恒轮回的体验，让真结局「葬花」更具冲击性。
游戏的配音方面，游戏在计划之初就决定是除男主以外角色全部安排配音，嵇零本打算找配音公司直接负责游戏的配音，不过由于价格问题而作罢。又与数个中国大陆的配音团队接触后，嵇零也并没有找到合适的配音团队。最后嵇零选择了《泡沫冬景》制作人古落推荐的森中人做配音导演并组建游戏的配音团队。游戏女主角双花的配音，森中人推荐了不少人，只是并不符合嵇零的要求。适逢年末，网易云音乐给用户的歌单出年度总结，嵇零发现自己歌单年度歌手是Hanser，萌生了邀请Hanser做双花配音的想法并主动联络了Hanser。Hanser在了解游戏和角色后，表示有兴趣而答应下来。配音的工作大部分在网络上完成，配音员们开网络讨论组，配音员在家配音由配音导演监听。部分重要的文段，配音员们在北京的录音室进行配音工作。
2022年1月14日，零创游戏在摩点展开众筹以筹得游戏追加下载内容（DLC）开发和周边制作的资金，计划中开发的DLC有「昼双花追加结局」和「严玥秋线」。由于制作组已经开启其他游戏专案，DLC的内容原计划是以较短边幅补充故事内容。1月末，嵇零在三亚偶然得知了刘学州事件，事件引起他对自杀等内容的思考，为此他扩充了DLC剧本的大纲，最后DLC文本量达到游戏本篇的一半。


== 发行 ==

《葬花》在2021年4月已经完成了开发。2021年6月12到13日制作组参加第二十八届上海ComiCup，在活动中宣传作品。6月16日到22日，《葬花》参加Steam游戏新品节，期间提供游戏Demo供玩家试玩，官方宣布游戏预计9月17日发售。9月24日，制作组表示由于游戏版号的申请进度不如预期，预计到2022年初才能获得游戏版号在中国大陆发行，为了不违背之前对关注游戏的玩家说在2021年末发布的承诺，制作组打算提早在10月22日于Steam发布游戏。游戏的Steam版本原本有发行商负责中国大陆的发行，不过后来相关合作终止，制作组只能自行宣传和发行。2021年10月22日，游戏正式发售，首周有发售折扣，女主角双花的配音员Hanser本身是bilibili知名Up主，在发售前后在bilibili直播游戏，给游戏做了宣传。游戏首周销量有24874份。发售一个月，销量达到三万份，制作组表示回收了全部制作成本。游戏原声带《葬花·原声音乐集》在11月5日免费在Steam发布。游戏发繁体中文版于2022年1月26日推出。
游戏的行动端原定于2022年初发售。2022年3月30日，游戏行动端在App Store和Google Play展开预售，发行由Fun Quarter负责。同年4月14日，游戏正式发售，发售初期有进行折扣推广。游戏的追加下载内容（DLC）《折镜之蝶》于7月22日推出，发售初期游戏本体和DLC有进行折扣推广。


== 评价 ==
《葬花》在2021中文恋爱游戏大赛中入围「最期待新作」。游戏在Steam发售获得极度好评，给与好评的玩家大多认为游戏的整体剧情很棒，配音不错，多条分支的剧情线路以及对《桃花源记》的再创作让人惊奇，给与负评的玩家指出游戏体量小，一笔带过的多结局体验存在缺陷。有部分玩家是因为Hanser声演女主角双花，所以了解到该游戏，不过他们在之后游玩过程中渐渐被悬疑剧情所吸引。
游戏媒体对作品的评价正面，GameDiary认为游戏的完成度相当高，中国大陆的AVG制作组数量有限，专业化程度参差的现状下，《葬花》展示了「一款精心雕琢的AVG所能达到的水平」。游戏角色的昼夜两个性格的设定让角色的层次感丰富很多，昼夜的形象透过美术和配音造成鲜明的反差，也能吸引玩家探究故事背后的真相。另外，支线角色的故事也有深度，值得玩家进行思考，游戏的演出有很多细节也能增加玩家的代入感。触乐编辑冯昕旸称赞《葬花》是一部相当优秀的作品，他给与游戏音乐、美术和故事正面的评价。同时他也指出游戏的剧情结构还有不少调整的空间，有太多重复的文段可以精简，此外真结局触发方式不够好。QooApp编辑废图小帮手给与剧情较高的评价，他表示「厚实且严谨的文本量堆砌出极出色的剧情体验」，「在游戏的早期对话便可轻松看出制作人 嵇零 对世界观和人物设定的考究之处，各个零碎桥段和登场人物全都环环相扣」。
