博明 (美国白宫官员)

博明（英语：Matthew Pottinger，1973年5月5日—，亦音译马修·波廷杰），是美国前白宫官员、新闻记者及美国海军陆战队军官。2019年至2021年担任美国副国家安全顾问。


== 早期生活 ==
博明是前司法部官员及作家约翰·史丹利·波廷杰的儿子。他在米尔顿学院接受教育，亦是约翰·埃夫隆的同学及童年朋友。博明毕业于麻州大学阿默斯特分校，获得了中国研究的大学学位，并能说流利的中文。


== 新闻事业 ==
在加入美国海军陆战队之前 ，博明在1998年至2001年期间担任路透社的记者。然后他转到《华尔街日报》，直到2005年从新闻界退休。他的报道获得了亚洲出版协会的奖项，并获得了普利策奖提名。他的报道涵盖多个主题，包括SARS流行病和2004年印度洋地震和海啸；在后者的任务中，他遇到了美国海军陆战队，并受到了他们的勇气的启发而决定离开新闻事业。他在中国工作了七年之久。


== 军人生涯 ==
2005年9月，博明加入海军陆战队，并担任军事情报官。他当时已届31岁，明显过老，体能亦不及格。在此前为了达到当中的体能要求，他与美国驻华大使馆工作的一名美国海军陆战队队员至万里长城上慢跑健身。从军期间他曾参与过至少3次的军事行动：一次是从2007年4月至同年11月的伊拉克战争，两次是从2008年11月至2009年5月以及2009年7月至2010年5月的阿富汗战争。在第二次阿富汗战争中，时为上尉的他会见了美国陆军少将迈克尔·弗林，并与他共同撰写了一份情报工作的报告。 该报告于2010年1月通过新美国安全中心发布，标题为「改善情报工作：使阿富汗情报工作适切的相关蓝图」。博明退役后在纽约市工作，包括在对冲基金公司戴维森·肯普纳资本管理公司工作。


== 政治生涯 ==
2018年，《政客》曾形容博明是一个「相对传统而保守的国际主义者」，而且「从不是川普式的超级保守派」，并会同时对共和及民主两党捐款。但于2017年，他加入了川普执政时的美国国家安全委员会。曾与博明于军队共事，当时的顾问迈克尔·T·弗林将博明遗定为亚洲主管，而他亦持续于H·R·麦克马斯特及罗伯特·C·奥布莱恩任职时继续留任此职位。
2018年朝美首脑会晤期间，川普曾一度称会晤将取消，而《纽约时报》亦在一篇有关会面的报道中引用一名白宫高级官员的资料，考虑到所需的计划内容而时间不足，即使恢复会议，也「不可能」在6月12日如期举行。当时川普指称《纽约时报》所提及的白宫官员根本不存在，而是《纽约时报》虚构出来。一日后，记者亚沙·阿里在Twitter上发表了当时新闻记者在白宫记者会上宫员讲话的音频，当中包括博明在回应记者提问时所提出的说法，此亦是提供了《泰晤士报》引述的简报资料 。其中虽然他实际上并没有使用「不可能」一词，但在回答记者关于于原定日期举行会面的可行性时，说到「我们已经浪费了很多需要的时间」、「而6月12日已是十分钟之内的日子」。 
在担任国家安全委员会的职位时，博明主张对中国采取强硬立场，并将贸易政策及国家安全层面相结合。 
2019年9月，新任的国家安全顾问罗伯特·C·奥布莱恩任命博明为副国家安全顾问。
2020年，博明在刘沙沙女士的提议下，藉中国庆祝五四青年节期间，以流利普通话并以借古讽今的形式，阐述以美国的视角看待五四精神，其内容及立场被认为是了解美国对华政策的重要引子，并引起华文媒体的广泛报导。
2021年1月6日，博明在2021年美国国会大厦遭冲击事件后辞去副国家安全顾问一职，并于1月7日正式离职。
2021年1月21日，中华人民共和国外交部宣布对28名美国人及其亲属实施制裁，博明是其中1人。


== 个人生活 ==
博明的妻子杨小燕博士（Yen Duong Pottinger）为越南裔美国人出身的微生物学家，育有两名孩子。
