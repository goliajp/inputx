约恩·安德森

庄恩·安达臣（挪威语：Jørn Andersen，1963年2月3日—）是一名德国籍挪威裔足球教练及前职业足球运动员。


== 球会生涯 ==
安达臣出身于家乡球会奥斯塞登（挪威丙组联赛），1982年赛季转投同市的甲组联赛球会费德列斯达展开职业生涯。1984年赛季，费德列斯达夺得挪威杯冠军，他在对维京的决赛和重赛均有入球，惟球会于同季降班。1985年赛季，安达臣转投本土劲旅华拉伦加并成为该季联赛神射手。
1985年年底，他出国加盟德甲球会纽伦堡。1988/89年赛季，他转会到法兰克福，并于1989/90年赛季成为史上首位夺得德甲联赛神射手的外籍球员，那年法兰克福争夺联赛冠军失败。1990/91年赛季，他转投杜塞尔多夫，次年重返法兰克福。1992/93年赛季，他缺席了大部份比赛，自此上阵时间大减，遂于1994年1月转投汉堡，一年后再转投位处榜未的德累斯顿戴拿模，球队排名最尾降班。由于球会因财困无法获得乙组联赛执照，需降级到地区联赛，所以他不得不离开球会。
1995/96年赛季，安达臣转到瑞士发展，加盟甲组联赛球会苏黎世。1997年1月，他转投乙组联赛球会卢加诺，球队于1998/99赛季重返甲组联赛。1999/00年赛季，他加入丙组联赛球会洛迦诺，兼任助理教练，球队于次年升班到乙组，他最后于2001年高挂球靴。


== 国际赛生涯 ==
安达臣于1985年起获挪威国家足球队征召，处子战是作客对东德的一场国际足球友谊赛。他的国际赛生涯到1990年10月终结，历来为国家队上阵共27次，打进5球。


== 教练生涯 ==
安达臣在退役前已在洛迦诺兼任助理教练。2001年退役后，他继续留在瑞士，于卢塞恩展开教练生涯，出任预备队主教练。
2003/04年赛季，他回到德国，出任德乙球会红白奥伯豪森主教练，带领球队由一支护级份子到最后仅以一分之差无缘升上德甲。
2005/06年赛季，他成为德甲球会慕逊加柏的助理教练，但他和他的主教练科佩尔同于季尾被终止合约。2006年世界杯后，安达臣曾有机会成为德国的助理教练，但德国足球协会和主教练路维最终选择了费历克。
2007年夏天，安达臣原已接受希腊超级联赛球会克桑西的两年主教练聘约，但在正式上任前就因与球会理念不合而解约。2007年11月，安达臣走马上任成为德乙球会奥芬巴克的主帅，球队最后与奥格斯堡同分，但得失球较差而需要降班。
2008/09年赛季，安达臣接替高普成为缅因斯新主帅，成功带领球队以第二名重返德甲，同年打入德国杯半准决赛，是他早期执教生涯的一大成就。
然而，他却在德甲新赛季开始前因与球会理念不合遭解雇，球队改由青年队教练杜曹接掌，在当时引起轰动。2010/11年赛季季中，他曾短暂执教希腊超级联赛球会拿尼沙，所执教的4场比赛全部败北，一球不进。
2011年11月，安德森执教德乙球会卡尔斯鲁厄，给哈坎·恰尔汗奥卢带来了在成年赛事的处子战。同年，他在巴伐利亚开设了一家足球学院。
2015年1月，已赋闲一段时间的安达臣毅然转到奥地利执教地区联赛球会奥地利萨尔斯堡，成功带领球会再次夺得联赛冠军，并在升班附加赛取胜，首次升上乙组联赛，成为职业球会。但到了2015年12月，球会因陷入财困需与他解约。


==== 朝鲜 ====
2016年5月，安达臣翻开其执教生涯的重要一页，经过长达半年的磋商后，他接受朝鲜国家足球队邀请出任主帅，成为朝鲜历史上第二位外籍的足球教练，这项决定受到挪威一些公众人物的非议。
他在这个封闭国家执教了接近两年的时间，与妻子寄居于平壤市中心高丽饭店的套房，享受贵宾级待遇。由于他没有助理教练跟随，只是透过翻译与球员交流。国家队球员平日一起在足协的训练中心集训，周末才回到球会比赛。
安达臣成功带领朝鲜出线2017年东亚杯和2019年亚洲杯决赛周，在A级比赛打出8胜4和3负的不俗成绩。2018年年初，因受到国际制裁下的财政压力，朝鲜未能再与安达臣续约。


==== 仁川联 ====
完成朝鲜队合约的他收到多家亚洲球会的聘书，于2018年6月决定选择成为韩国职业联赛球会仁川联的主帅，2019年4月因球队在新球季表现低迷被辞退。


==== 香港 ====
离开韩国后，安达臣因新型冠状病毒大流行而赋闲了一段时间，他曾有机会成为冰岛的主帅。2021年12月，安德森上任执教香港足球代表队，香港足球在2022年初受第五波疫情严重影响，自2月以后，该季所有本土赛事被腰斩，当时他几乎要考虑放弃这份工作。
2022年6月亚洲杯外围赛，安达臣带领的香港队在不被看好下，采取全场压迫战术，先后击败阿富汗及柬埔寨，虽然最后一仗负于主队印度，但已足以取得最佳次名的身份。香港队自1968年以来，54年后再次挤身亚洲杯决赛周。
2023年9月至10月，安德森带领香港U23出战2022年杭州亚运男子足球比赛，球队先后于十六强和八强击败巴勒斯坦U23和四届冠军伊朗U23，历史性首次晋级四强。球队最后不敌日本U23和乌兹别克U23，以殿军成绩写在历史册上。
2024年1月，香港队在阿联酋备战亚洲杯决赛周，在一场国际友谊赛中击败中国，是39年来首次。


==== 云南玉昆 ====
2024年6月，安德森出任中甲球会云南玉昆主教练一职，成功协助球队提前四轮升上2025年中超联赛。

== 个人生活 ==
安达臣的母亲芭约（Bjørg Andersen）是前挪威国家手球队成员，有143次上阵纪录，曾参加三届世界女子手球锦标赛。安达臣在德国结识了他的妻子乌娜（Ulla Andersen），当时她在平治车厂工作。他们于 1988 年结婚，育有两名子女。他的儿子历卡斯亦是一名足球员，曾在德国各级联赛发展。安达臣于1993年放弃挪威国籍，归化成为德国公民。
