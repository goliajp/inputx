2004年乌克兰总统选举

2004年乌克兰总统选举于2004年10月31日举行。如果无人得到过半数选票就将会于11月21日举行第二轮投票。本次选举是乌克兰在1991年从前苏联独立之后的第四次总统选举。


== 背景 ==
2004年11月21日，由反对派领导人尤先科与时任总理维克多·亚努科维奇进入第二轮投票决一胜负。这次选举是于一个极度紧张的政治气氛下举行，因为传媒多数报导当局恐吓选民和反对派候选人尤先科怀疑被对手落毒陷害而身中二𫫇英剧毒。
根据乌克兰选举法，两轮选举制适用于总统选举中，候选人必须赢得所有的选票的过半数（50%以上）才会当选。第一轮投票2004年10月31日举行，由于没有候选人获得50％以上的选票，得票最高的两名候选人，尤先科和亚努科维奇会进入决胜轮投票中。第二轮投票于11月21日举行。根据乌克兰中央选举委员会在11月23日公布之结果，第二轮投票中亚努科维奇获得最多票数而胜出了本场选举。但选举结果被尤先科和其支持者与很多国际观察员指本场选举涉及舞弊成份，而对是次选举结果不予承认。
而这次事件导致乌克兰爆发政治危机，被称为「橙色革命」。和平示威者呼吁当局应重新举行第二轮投票选举。最后乌克兰最高法院正式下令取消第二轮投票结果，并下令须重新举行第二轮投票。
12月26日，第二轮投票经重新举行，结果由尤先科胜出。国际观察员的报告指出经重新举行的第二轮投票比前一次的第二轮投票更公平。


== 候选人 ==
本场总统选举共有二十六位参选人被提名及参与。
而选举中的两大对手分别为时任总统的候选人亚努科维奇和反对派领导人尤先科。
亚努科维奇从2002年开始担任乌克兰总理一职直至选举，他获得将卸任的总统库奇马和时任俄罗斯总统普京支持。
而尤先科就表示其亲西方的立场，所以获得欧盟国家与美国支持。

== 首轮投票 ==

在2004年总统选举的初步投票在10月31日举行，2004年官方记录结果尤先科以39.87个百分点得票率领先亚努科维奇的39.32个百分点。由于没有候选人已获得50％的绝对胜利票数，第二轮投票已定于11月21日举行。虽然在第一轮投票有高达75％的投票率，但观察员的报告揭示出许多违规行为，特别是被视为最支持尤先科的地区。目前还不清楚这些行为对结果有多少的影响。

== 第二轮投票 ==

在11月21日决胜轮投票中，乌克兰选举委员会宣布亚努科维奇总理与尤先科所得的选票分别为49.42％和46.69％。欧洲安全与合作组织（OSCE）表示本次选举并不符合「国际标准」，而美国资深选举分析员Richard Lugar称其为「选举日的实行了一项协调一致和强而有力的欺诈方案」（concerted and forceful program of election day fraud）。


== 国际反应和影响 ==
许多评论家认为选举受到外部势力，特别是美国、欧盟和俄罗斯的影响。美国支援尤先科（美国国务卿亨利·基辛格、前美国国家安全顾问布热津斯基和美国参议员约翰·麦凯恩都以官方或私人身份访问过基辅)，而俄罗斯总统普京则公开支援亚努科维奇。在媒体中曾对两位候选人进行对比分析，尤先科代表亲西方基辅居民以及农村的乌克兰人，而亚努科维奇代表东欧、亲俄的工业劳动者。
更具体地说，尤先科胜利将代表乌克兰和其他独立国家联合体国家间的融合停止，并且可能取消乌克兰与欧亚经济共同体中俄罗斯、乌克兰、白俄罗斯和哈萨克斯坦之间的经贸协议。他可能反而进一步增加乌克兰融入欧洲和可能成为欧盟和北约的成员国。亚努科维奇已经答应会像其他独联体国家如白俄罗斯、哈萨克斯坦和吉尔吉斯斯坦把俄罗斯语定位其中一种官方语言。


== 重新第二轮投票 ==
重新进行投票的最后结果记录，尤先科获得51.99%的选票，而亚努科维奇则获得44.19%的选票。于11月21日投票相比，尤先科票增加5.39%，而亚努科维奇则减少5.27%。
亚努科维奇承在2004年12月31日承认失败和随后在同一天辞去乌克兰总理职务。尽管尤先科胜利，在重新第二轮投票中可得知，支持各候选人的区域保持不变。南部和东部省份够支持亚努科维奇，西部与中部地区则支持尤先科。
乌克兰最高法院在一月六日拒绝了亚努科维奇对选举选举委员会举行的选举之上诉申请。
2005年1月10日乌克兰选举委员会正式宣布尤先科获胜，然后在1月11日公布最终选举结果，为尤先科通向总统宝座的道路扫除障碍。官方就职仪式在1月23日约中午时分举行，尤先科根据宪法宣誓就任总统，成为第五任乌克兰总统。
2009年11月亚努科维奇表示，虽然他在选举中的胜利最后被「带走」，但他认为是自己放弃了这场胜利以避免流血冲突。他说：「我不想母亲失去她们的子女和妻子失去她们的丈夫。我不想尸体从基辅流入第聂伯河。我不想通过流血掌权。」


== 后续发展 ==
尽管声称令人信服的证据指出前任乌克兰总统列昂尼德·库奇马曾涉及选举舞弊，不过乌克兰中央选举委员会指因没有刑事选举欺诈的指控存在，所以并没有起诉任何高级官员。乌克兰总检察官逮捕了几个公众人物。在2005年上半年开始审理选举舞弊指控，但没有引人注目的疑犯被移交法院。2005年9月23日，在尤先科宣布一项与地区党的协定中，他答应特赦在2004年乌克兰总统选举期间因操纵选票而被定罪者。
2010年乌克兰总统大选期间，亚努科维奇的竞选承诺中提及要防止选举舞弊，他表示：「我们将妥善应对所有挑衅和企图制造假选举结果。」
