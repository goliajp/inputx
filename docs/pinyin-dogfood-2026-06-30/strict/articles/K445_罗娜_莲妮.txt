罗娜·莲妮

罗娜·莱格特·莲妮（英语：Laura Leggett Linney，1964年2月5日—）是一名美国女演员兼导演，曾获得多项奖项，包括四座黄金时段艾美奖、两座金球奖与一座美国演员工会奖，并曾入围三次奥斯卡金像奖、五次东尼奖以及一次英国电影学院奖。
琳妮于1990年在百老汇初次登台，其后凭借2002年重演的《激情年代》、2004年的百老汇原创作品《Sight Unseen》、2010年的《Time Stands Still》、2017年重演的《The Little Foxes》，以及2020年的《My Name Is Lucy Barton》，多次获得东尼奖提名。
在电视方面，她凭2001年的电视电影《Wild Iris》赢得首座黄金时段艾美奖，其后又凭2003年至2004年的情境喜剧《欢乐一家亲》与2008年的迷你影集《John Adams》再度获奖。2010年至2013年，她主演Showtime影集《如果还有明天q》，并于2013年凭此剧获得第四座艾美奖；2017年至2022年，则主演Netflix犯罪影集《黑钱胜地》。
作为电影演员，琳妮以1992年的《罗伦佐的油》中的小角色出道，其后凭2000年的剧情片《我办事，你放心》、2004年的《金赛性学教授》与2007年的《亲情触我心》三度获得奥斯卡金像奖提名。她亦因在1995年的《刚果惊魂》、1996年的《一级恐惧》、1998年的《楚门的世界》、2003年的《神秘河流》与《爱是您·爱是我》、2005年的《亲情难舍》、2007年的《豪门保姆日记》、2012年的《当总统遇见皇上》、2015年的《福尔摩斯先生》，以及2016年的《萨利机长：哈德逊奇迹》与《夜行动物》中的演出而闻名。


== 早年生活与教育 ==
琳妮于1964年2月5日出生于纽约市曼哈顿。其母亲米丽安·安德森·「安」·珀斯（Miriam Anderson "Ann" Perse，娘家姓Leggett）曾任职于纪念斯隆-凯特琳癌症中心的护士，父亲则是剧作家兼教授罗穆勒斯·撒迦利亚·林尼四世（Romulus Zachariah Linney IV）。琳妮童年时常于夏季前往新罕布夏州与父亲同住，并自11岁起参与当地剧团活动，从此爱上舞台。她的父系高祖父为美国共和党籍联邦众议员罗穆勒斯·撒迦利亚·林尼（Romulus Zachariah Linney）。她另有一名同父异母的姊妹苏珊，来自父亲的第二段婚姻。
琳妮于1982年自Northfield Mount Hermon School毕业；该校是一所位于麻萨诸塞州的预备学校，而她后来亦担任该校艺术顾问委员会主席。其后，她先后就读于西北大学与布朗大学，并于布朗大学期间师从吉姆·巴恩希尔（Jim Barnhill）及John Emigh学习表演，也曾担任校内学生剧团Production Workshop董事会成员。在布朗大学四年级时，她曾在父亲的戏剧作品《Childe Byron》制作中饰演爱达·勒芙蕾丝夫人（Lady Ada Lovelace）；该剧讲述诗人拜伦勋爵与其女儿艾达之间紧张而疏离的关系逐渐修补。
琳妮于1986年自布朗大学毕业，之后进入茱莉亚学院研习表演，为第19组（1986年至1990年）学员，同组成员还包括珍妮·翠柏虹与提姆·布莱克·尼尔森。2003年，她获布朗大学授予荣誉美术博士学位。2009年，她于茱莉亚学院发表毕业典礼演说时，亦获该校授予荣誉美术博士学位。


== 职业生涯 ==
琳尼于1990年在纽约舞台上首次亮相，在外百老汇改编的《海鸥》中饰演妮娜，故事背景设定在汉普顿。这部广受好评的作品由杰夫科恩构思和执导，在字母城的RAPP艺术中心展出，获得了广泛好评。《纽约时报》写道：「最棒的是琳尼小姐饰演的妮娜。她饰演的妮娜从一个天真、理想主义的艺术家追随者，带著疯狂的决心，变成了一个比身受绝症的鸟女更坚强、更复杂的女人。她显然是一个具有巨大潜力的人才」。


== 个人生活 ==
琳妮于1995年9月2日与演员大卫·阿德金斯（David Adkins）结婚，两人于2000年离婚。
2007年，她与来自科罗拉多州特柳赖德的药物与酒精咨商师马克·绍尔（Marc Schauer）订婚。2009年5月举行婚礼时，由演员连恩·尼逊陪同步入礼堂。两人育有一子，于2014年出生。
琳妮曾于2009年1月18日出席并担任世界一体：欧巴马林肯纪念馆就职庆祝活动的嘉宾与主持人之一。

== 获奖纪录 ==

琳妮曾获得多项奖项与荣誉，包括2座金球奖、4座黄金时段艾美奖与1座美国演员工会奖，并曾获英国电影学院奖及5项东尼奖提名。
琳妮亦曾3度获美国电影艺术与科学学院提名奥斯卡金像奖：

第73届奥斯卡金像奖：以《我办事，你放心》（2000年）获提名奥斯卡最佳女主角奖
第77届奥斯卡金像奖：以《金赛性学教授》（2004年）获提名奥斯卡最佳女配角奖
第80届奥斯卡金像奖：以《亲情触我心》（2007年）获提名奥斯卡最佳女主角奖
