2023年特维尔州飞机坠毁事故

2023年特维尔州飞机坠毁事故，是指2023年8月23日在莫斯科西北方的特维尔州库任基诺发生的一起坠机事故。一架由莫斯科飞往圣彼得堡的莱格赛600型私人飞机坠毁，机上七名乘客和三名机员全部死亡。
这次事件中，瓦格纳集团雇佣兵头目叶夫根尼·普里戈任及其副手德米特里·乌特金（代号“瓦格纳”，是瓦格纳集团最初的创始人之一）均在坠机中当场身亡。事件发生后一度有普里戈任并未在飞机上的传言，但在对现场寻获对尸体的初步判别中，普里戈任的尸体因其缺失的手指被识别，而乌特金的尸体则靠他身上的纳粹纹身被辨别出来。随后俄国当局进行的DNA检测亦证实普里戈任和乌特金均已死亡。


== 背景 ==
普里戈任1961年出生于苏联列宁格勒（今圣彼得堡），1990年代起在家乡凭饮食业发迹，借此结识当时在圣彼得堡出任第一副市长（现为俄罗斯总统）的普京，并成为后者亲信，后来被称为「普京的大厨」。
到2014年，普里戈任成立雇佣兵组织「瓦格纳集团」，参与叙利亚内战，后来将业务逐渐扩展至非洲。到2022年俄罗斯入侵乌克兰后，瓦格纳集团长期主攻乌克兰东部城镇巴赫穆特，巴赫穆特战役被形容是俄乌战争最血腥的战役。
惟瓦格纳集团与俄罗斯正规军的龃龉也在其间逐渐浮面，普里戈任批评正规军作战不力，并质疑瓦格纳集团被俄罗斯国防部扣起弹药，甚至屡次点名炮轰俄罗斯国防部长绍伊古和俄军总参谋长格拉西莫夫。这些矛盾在2023年6月23日升至高峰。普里戈任发布影片，指摘俄罗斯军方对瓦格纳集团发动导弹袭击，宣称要「正义进军」。瓦格纳部队同日深夜在侵乌指挥部、俄军南部军区总部所在的顿河畔罗斯托夫发起兵变，向莫斯科长驱直进，但翌日晚上宣布停止推进，兵变在一日内落幕。白俄罗斯总统卢卡申科表示自己出面斡旋，普京同意给予瓦格纳武装人员安全保障，普里戈任则率众转移到白俄罗斯。此后普里戈任行踪成谜，不时传出他在俄白两国游走。2023年8月21日，普里戈任发表身穿迷彩军服的短片，背景是沙漠，外界揣测他身处非洲。
据与瓦格纳集团关系密切的消息来源称，格鲁乌副局长领导并计划由一支筹备中的平行雇佣军团体取代瓦格纳的大部分成员。据称，普里戈任极力抵制此计划，并因而从马里紧急返回俄罗斯，以图阻止该情况发生。
根据航空网站International Aviation HQ，巴西航空工业公司的莱格塞600型飞机于2002年起提供飞航服务，直到2020年停产前，共生产近300架。这款公务型喷射机飞航20多年仅发生过1次意外，2006年一架全新的此型飞机在从巴西航空工业公司当地工厂飞往美国交付途中，与高尔航空一架波音737-8EH（SFP）型飞机空中相撞。这架莱格赛600型飞机虽受损，但机师将飞机紧急降落在巴西一个空军基地，机上7人无人伤亡；但737因受损严重空中解体坠毁于热带雨林中，机上154人全部遇难。随后调查将责任归咎于人为而非机械故障，涉事飞机在停场多年后被修复并转手。


== 事故经过 ==

普里戈任乘搭的私人飞机，大约于2023年8月23日当地时间18时正于莫斯科起飞，计划前往圣彼得堡。根据航班追踪网站Flightradar24公关主任佩特切尼克，飞机原本毫无异状，直到当地时间18时19分，飞机于30秒内「突然垂直下坠」，从28,000英尺的飞行高度急坠超过8,000英尺。佩特切尼克表示，「不管发生了什么事，一切都来得很快……事发后，他们也许一直在（与飞机）搏斗」，但在急坠之前，「毫无迹象显示飞机有任何问题」。
飞机疑似在俄罗斯境内特维尔州库任基诺镇附近被俄罗斯空军击落，距其出发点莫斯科以北约六十英里。这架飞机是巴西飞机制造商巴西航空工业公司制造的私人飞机；据报导指这架飞机可能是普里戈任的私人飞机巴西航空工业莱格赛600飞机。然而俄新社声称飞机属于商业运输公司「MNT-Aero LLC」所有。在坠机当时，普京正在库尔斯克举行的会战胜利80周年活动上发表讲话。
俄罗斯联邦航空运输署表示，俄罗斯雇佣兵组织瓦格纳集团创办人普里戈任和乌特金均在乘客名单上，但是也曾有Telegram频道声称普里戈任在另一架飞机上。
俄罗斯官方称飞机在空中飞行不到半小时就在着陆时起火，但与瓦格纳集团相关的Telegram频道“The Grey Zone”声称这架飞机是被俄罗斯防空系统击落。据报导指，飞机上已发现全部10具尸体。在堕机事故数分钟后，社交网路出现了飞机坠毁的画面，但该影片实际上是6月24日瓦格纳兵变时击落的俄军电子战飞机下坠画面。
2023年8月24日，俄罗斯当局表示，失事客机乘客全部尸体均已找到。警方封锁了坠机地点周围地区，俄罗斯联邦航空运输署亦成立了相关特别委员会实施调查。俄罗斯联邦侦查委员会也表示针对“违反航空运输安全规则”展开调查。
2023年8月25日，俄罗斯联邦侦查委员会表示侦查人员已在事故现场取得10具尸体和失事飞机飞行记录仪，正在检测尸体DNA以确认其身份。27日，俄方发布消息称DNA检测结果确定坠机现场寻获的其中一具尸体是普里戈任。


== 罹难者名单 ==

俄罗斯联邦航空署公布了遇难者的姓名。名单上列出的十人中，其中七人是乘客：

叶夫根尼·普里戈任：瓦格纳集团的创始者、最高领袖及发言人。
德米特里·乌特金：瓦格纳军事总司令。
谢尔盖·普罗普斯汀：瓦格纳高层指挥官，参加过第二次车臣战争，于2015年加入瓦格纳。
叶夫根尼·马卡良：普里戈任保镖，第四突击分队指挥官，曾是一名地区警察，于2016年3月加入瓦格纳。
亚历山大·托特明：普里戈任保镖。
瓦列里·切卡洛夫：瓦格纳总军需官，负责内部安全、物流后勤、军需粮草、农业生产、地质勘探、油矿业务等项目，普里戈任最信任的心腹之一。
尼古拉·马图耶夫：瓦格纳高层指挥官。
阿列克谢·列夫辛：机师。
鲁斯塔姆·卡里莫夫：副机师。
克里斯蒂娜·拉斯波波娃：服务员。
国际文传电讯社表示已经寻获10人的遗体。根据BBC引用与瓦格纳领导层关系密切的Telegram频道「The Grey Zone」的说法，以及俄罗斯媒体帝都电视台援引匿名消息人士以及俄罗斯军事Telegram频道「VChK-OGPU」的说法，推定普里戈任已在空难中身亡。此外，华尔街日报、美联社、半岛电视台、政客等多间媒体均推定普里戈任已死。有消息人士表示普里戈任的手机在坠机现场的一具尸体旁边被发现，初步确定了普里戈任的尸体。


== 事故原因 ==
坠机成因有众多疑问。网路上流传的坠机现场图片显示，失事飞机上有疑似弹孔的痕迹。而亲瓦格纳Telegram频道「The Grey Zone」宣称是俄军防空导弹将飞机击落，引述当地居民指事发时有两声巨响，目击两道冒烟的痕迹，与防空系统开火特征相似。惟有分析质疑以飞机当时高度需至少出动中程导弹才能将其击落，而且机身一体掉落地面，不似是被弹头或碎片击中。路透社在2023年8月24日报导指美国军方正在研究有关普里戈任飞机坠毁多种可能原因，其后引述美国高官指，初步分析显示客机是被地对空导弹击落。惟后来美联社再引述美国和西方官员指，坠机是在飞机上蓄意引发爆炸所致。美国国防部发言人赖德也否认飞机是被地对空导弹击落。
12月22日，华尔街日报援引西方情报和前俄罗斯情报官员消息报道，俄罗斯联邦安全会议秘书和前俄罗斯联邦安全局局长尼古拉·帕特鲁舍夫下令暗杀普里戈任，总统普京知情但没有反对。


== 相关猜测 ==
在事故发生前两个月，普里戈任、乌特金和切卡洛夫三名瓦格纳集团领导人曾经公然发动兵变违抗普京总统的政权，尽管普里戈任以前是普京重要的盟友。而叛乱通过相对温和的方法谈判解决，让普里戈任逃脱处罚。BBC援引分析人士的说法，这种相对低调的处理方式使他们认为普里戈任是一个「朝死路上走的人」。
根据俄语独立媒体Meduza访问克里姆林宫内部人士有关普里戈任之死，其表示「我有预感他的结局很糟糕，（克里姆林宫）不会原谅这样的事情」，而普京判断普里戈任不再是一个「可靠且易于管理的人」。克里姆林宫内部人士向Meduza称普里戈任在叛变失败后「没有学到任何东西」，并继续在俄罗斯做生意并会见了莫斯科市长办公室和地区政府的官员，讨论公共部门机构的食品供应问题。消息人士表示「考虑到风险问题，为什么他（普里戈任）仍然需要在这里签订学校供餐合同？」
卡内基俄罗斯欧亚中心高级研究员斯塔诺瓦亚表示，无论是什么原因导致了飞机失事，每个人都会将其视为克里姆林宫对不忠之人的报复与恐吓，因此俄罗斯政府也就抱持著模糊的态度，但斯塔诺瓦亚认为有充分理由相信普京参与了这起事故。
根据美联社援引匿名美国情报官员的说法，其初步评估普里戈任「很可能」早就成为暗杀目标，此次空难符合普京「长期以来试图压制批评者的历史」。
乌克兰总统顾问波多利亚克怀疑这不是意外事件，而是普京在为2024年俄罗斯总统选举准备和肃清威胁，因为在不久前的2023年6月普里戈任曾带领瓦格纳集团发动兵变，但后来失败流亡白俄罗斯。同日，苏罗维金因可能支持瓦格纳集团兵变而被解除俄罗斯空天军司令职务。
2023年9月8日，乌克兰总统泽连斯基声称掌握俄罗斯总统普京下令刺杀普里戈任重要证据。


== 各方反应 ==
 瓦格纳集团其他高层指挥官表示，他们不会忍受普里戈津之死，并承诺将寻求报复。他们声称：「若普里戈津死亡消息得到证实，我们将在莫斯科组织第二次『正义行军』！他最好还活著，这对你们（俄军）比较有利，最好这次事件也与你们（俄军）无关。」
 美国总统乔·拜登在接受传媒采访时表示，「我不知道确实发生了什么，但我并不感到意外。」拜登亦推测，「俄罗斯发生的很多事情是普京背后支持，但我了解的还不够多，不知道答案。」
 乌克兰总统弗拉基米尔·泽连斯基被问及普里戈任死亡一事时称，乌克兰与此事无关，「大家都知道谁与此有关」。他又称，俄罗斯政府、普里戈任及其雇佣兵造成多人死亡，「对这些『非人类』没有什么好话要说，（他们）不是被海牙国际法庭审判，就是要被上帝审判」。
 乌克兰总统顾问米哈伊洛·波多利亚克在社交媒体上写道，在普里戈任与「瓦格纳集团」意图兵变后的两个月消灭他们，显示普京要在2024年俄罗斯总统大选前向国内菁英发出讯号：「小心点！不忠诚就得死。」
 飞行器制造商巴西航空工业公司不愿对事故置评，仅表示「公司一直遵从国际对俄罗斯的制裁」。
 俄罗斯总统弗拉迪米尔·普丁向特维尔州飞机失事遇难者家属表示哀悼，同时表示在事故中遇难的瓦格纳公司员工为俄乌战争作出了巨大贡献。普京亦表示据自己所知，普里戈任是在飞机失事当天才从非洲返回的，当时他还会见了某些官员。他称普里戈任是「一个命运多舛的人，犯过严重的错误，但他为自己和我所倡导的共同事业取得了需要的成果。他是个有才华的人」。普京承诺将彻查坠机事故。克里姆林宫方面否认普京与坠机事故有关。10月5日，俄罗斯总统普京表示根据调查结果，飞机坠毁前未受外部冲击，调查人员在遇难者遗体中发现了手榴弹碎片。
 车臣首脑拉姆赞·卡德罗夫表示向普里戈任的家人和朋友们致以深切的哀悼。他在Telegram的个人频道中表示「毫无疑问，他对特殊军事行动做出了巨大贡献，这份功劳不容否认。他的去世对整个国家来说都是一个巨大的损失。」但他也说普里戈任看不清国内局势，表示「我曾要求他为至高无上的国家事务放弃个人野心。其他事情可以以后再决定，但他却以他坚毅的性格和达成目标的渴望，坚持在当下追求他的目标。」
亲瓦格纳集团的Telegram频道「The Grey Zone」事发后不久确认普里戈任（其后还有集团二号人物乌特金）的死讯，其声明最后一句写道：「惟即使身处地狱，他也会是最佳！荣耀归于俄罗斯！」这句话并非「诅咒」，而是呼应普里戈任的「自我预言」。在「The Grey Zone」后来披露的旧访问片段中，普里戈任谈到自己的死亡观时称：「我们都会下地狱，但我们会成为地狱中最好的。」乌特金在片段中没有露面，但听到他说：「死亡不是结束，而是其他事情的开始。」
 俄罗斯反对派：与乌克兰阵营并肩作战的「俄罗斯志愿军团」指挥官杰尼斯·尼基廷呼吁「瓦格纳集团」佣兵倒戈加入他们的行列，为瓦格纳创办人普里戈任及其指挥官乌特金的死报仇。
 白俄罗斯：白俄罗斯总统卢卡申科表示普京不可能下令杀死普里戈任。他还表示自己曾提醒普里戈任要小心。


== 悼念 ==
在堕机事故发生后当晚，悼念空难遇难者的人聚集在圣彼得堡与瓦格纳集团或普里戈任相关的建筑物，献上鲜花、蜡烛和瓦格纳徽章等悼念品。根据CNN的报导指，公众在瓦格纳总部外展开了一面大横幅，上面写著：「瓦格纳PMC。我们在一起。」
2023年8月29日，普里戈任被埋葬于圣彼得堡波克罗夫斯科耶公墓，葬礼以私人形式举行。克里姆林宫发言人佩斯科夫表示俄罗斯总统普京没有计划参与葬礼。


== 评论 ==
战争研究所认为，瓦格纳集团高层在空难中死亡意味着该集团可能不再作为一个准独立的平行军事结构而存在，并影响其意图对普京政权削弱其行动的努力。并导致被俄罗斯政府吞并或摧毁该组织。
《华盛顿邮报》报导，有部分俄罗斯专家认为普里戈任之死将暂时消除俄罗斯精英阶级中任何剩余的挑战普京的冲动，说道「因为这样做的成本大幅上升了」，进一步巩固普京的统治。俄罗斯企业高管表示，他们在事件后越来越不愿意批评俄罗斯入侵乌克兰，同时担心，对于俄罗斯政府具建设性的批评也可能会招致报复。
