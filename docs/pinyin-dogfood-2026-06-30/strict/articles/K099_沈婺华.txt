沈婺华

沈婺华（约555年—627年），吴兴郡武康县（今浙江省德清县)人，陈后主陈叔宝的皇后。父亲为仪同三司、望蔡贞宪侯沈君理，母亲为陈高祖陈霸先女会稽穆公主，出身高贵。史书称誉沈婺华：“性端静，有识量，寡嗜欲，聪敏强记，涉猎经史，工书翰。”


== 幼年 ==
沈婺华幼年丧母，在守丧期间因过度哀伤而极其消瘦。即使丧期结束后，每逢年节或朔望之日仍常独自哭泣，不仅让她身边的人深受感动，更是传遍了整个阖府内外，大家都对她既尊敬又感到她与众不同。


== 皇太子妃 ==
陈宣帝太建元年七月初四（569年8月1日），沈婺华被册立为皇太子妃。
太建五年（573年）孙姬因生陈胤难产而死，沈婺华怜悯陈胤而养，视如己出。同年沈婺华父亲沈君理去世，她为父守丧，迁居别殿，哀毁逾礼。


== 皇后 ==
太建十四年（582年）陈后主陈叔宝即位，于正月己巳立沈婺华为皇后。陈后主继位初因陈叔陵之乱伤卧于承香阁下，唯贵妃张丽华可侍疾，沈婺华另外居住在求贤殿。在宠幸张丽华之前，陈后主对待沈皇后就已经非常冷淡了，故张丽华总后宫之政，但沈婺华从不曾流露一丝的嫉妒或怨恨。
沈皇后性情端庄娴静，少有嗜好与欲望，聪慧过人，记忆力强，广泛涉猎经史典籍，并擅长书法与写作。其才学修养很可能在年少时深受父亲沈君理的影响。她的日常起居俭朴，衣着不尚锦绣华服，身边近侍仅百余人，日常唯研读图史、诵念佛经。曾“遇岁旱，自暴而诵佛经，应时雨降”。
沈婺华无子，仅养子陈胤，当沈婺华成为皇后时，陈胤也为被立为皇太子。但后来因为沈婺华身边的侍从们频繁地与东宫往来，太子陈胤也屡次派遣人前往她的居所，后主怀疑他们心怀怨恨以及不该有的权位指望，非常厌恶他们。与此同时，张贵妃和孔贵嫔又日夜不停地罗织皇后和太子的短处，孔范之流的人又在宫外串通配合。到了祯明二年夏陈后主废掉庶长子陈胤，立张丽华的长子陈渊为皇太子，同时对沈婺华更加冷落与不满。
沈婺华多次上书劝谏，可是陈后主因此想废黜沈婺华，改立张丽华为皇后，但因陈灭亡不果，之后她随同陈后主一同被迁至长安。


==== 与陈后主诗歌酬答 ====
据《平陈录》记载，一次陈后主前往沈婺华的宫中，但短暂停留，随即准备离开。临行前，他问沈婺华为何不出言挽留，并作诗一首《戏赠沈后》：“留人不留人，不留人也去。此处不留人，自有留人处。”面对陈后主的“戏赠”，沈婺华同样以诗回答，即《答后主附》：“谁言不相忆，见罢倒成羞。情知不肯住，教遣若为留。”


==== 隋军入台城时居处如常 ====
当隋军攻入建康台城，与陈后主躲入枯井不同，沈婺华居处如往常一样，未失皇后风范。


== 亡国后 ==
仁寿四年（604年），陈后主陈叔宝去世，她亲自为赋哀辞，文辞恳切真挚，情感深沉动人。
隋炀帝每次巡幸，均令沈婺华随驾。
大业十四年（618年），隋炀帝为宇文化及所害，沈婺华自广陵过江，于毗陵天静寺为尼，法名观音。贞观初年（627年）去世。
据《隋书·卷三十五·志第三十》著录，有《陈后主沈后集》十卷，早佚。
