龙棋

龙棋（Dragon Chess），是1985年由加里·吉盖克斯在龙与地下城杂志推出的国际象棋变体，作为龙与地下城中的游戏。


== 棋具 ==
3*12*8方格的多层棋盘，三层分别名为天空、地上、地底。
棋子兵种共十五种，每方各四十二枚：
天空：龙（Dragon）一枚、狮鹰（Griffin）两枚、风精（Sylph）六枚
地上：国王（King）一枚、法师（Mage）一枚、圣武士（Paladin）一枚、僧侣（Cleric）一枚、英雄（Hero）两枚、盗贼（Thief）两枚、独角兽（Unicorn）两枚、猛玛（Oliphant）两枚、战士（Warrior）十二枚
地底：元素（Elemental）一枚、蜥怪（Basilisk）两枚、矮人（Dwarf）六枚。


== 规则 ==
两方轮流动一著。移动若至敌棋处，则将该敌棋移除游戏。
以将死敌方国王为胜。
僵死或连续用同一子将军为和局。


=== 棋子移动 ===


==== 天空层棋子 ====


===== 风精(S) =====
在天空:
往斜前方移动一格至空处，或往正前一格至敌棋处。
往正下方一层吃敌棋。
在地上:
往正上方一层的空处。
回到该棋种初始布置的空处，不受其他棋子抵挡。


===== 狮鹰(G) =====
在天空:
移动如国际象棋的骑士。
可往斜下方一层吃敌棋。
在地上:
斜向一格至空处或敌棋处。
往斜上方一层至空处。


===== 龙(R) =====
在天空:
移动如日本将棋的龙马
不移动，吃掉正下方一层或邻边格下一层的敌棋。


==== 地面层棋子 ====


===== 战士(W) =====
在地面:
移动如国际象棋的士兵，但不能走两格。至底行时升级为英雄。


===== 猛玛(O) =====
在地面:移动如国际象棋的城堡。


===== 独角兽(U) =====
在地面:移动如国际象棋的骑士。


===== 英雄(H) =====
在地面:
斜向一到两格至敌棋处或空处。
往上或下一层至邻格的敌棋处。
在天空或地底:
往上或下一层至邻格的敌棋处或空位处。


===== 盗贼(T) =====
在地面:移动如国际象棋的主教。


===== 僧侣(C) =====
在任何层:
移动如国际象棋的国王。
往上或下一层至正上或正下方的敌棋处或空位处。


===== 巫师(M) =====
在地面:移动如国际象棋的皇后。
在天空或地底:
往邻边移动一格至空位或敌棋处。
在任何层:往上或下移动一到两层至敌棋处或空位处。


===== 国王(K) =====
在地面:移动如国际象棋的国王。
往上或下一层至正上或正下方的敌棋处或空位处。
在天空或地底:
回至地面层离开的棋格，须为空位处，不受其他棋子抵挡。


===== 圣武士(P) =====
在地面:移动如国际象棋的国王或骑士。
2*3对角格的上或下层的敌棋处或空位处。
在天空或地底:
移动如国际象棋的国王。
2*3对角格的地面层空位处。


==== 地底层棋子 ====


===== 矮人(D) =====
在地底:
往正前方、横向移动一格至空处，或往斜前一格至敌棋处。
往正上方一格至敌棋处。
在地面:
往正前方、横向移动一格至空处，或往斜前一格至敌棋处。
往正下方一层至空处。


===== 蜥怪(B) =====
在地底:
往斜前方、正后移动一格至空处，或往正前一格至敌棋处。
在正上方一层的敌棋无法移动。


===== 元素(E) =====
在地底:
正向移动一到两格至空处或敌棋处。
斜向移动一格至空处。
正向移动一格至空处，然后往正上一层至敌棋处。
在地面:正向移动一格至空处，然后往正下一层至敌棋或空处。
