朱小荪

朱小荪O.O.M. （英语：Jim Chu，1959年—），华裔加拿大人，出生于中国上海，1962年随家人移民加拿大，在温哥华长大。曾任温哥华警察局局长 。2007年8月15日上任直至2015年，是加拿大歴史上的首位华人警察局长。
朱小荪在警队生涯中认识了同是任职温市警队的白人女子薇琪（Vicki，现已退役），后来更堕入爱河，1985年共结连理。目前两人育有4名子女。
朱小荪不会粤语，也不懂普通话，但能听和讲流利上海话，不过他以讲英语为主。


== 早年生活 ==
朱小荪3岁时（1962年）随父母从中国上海移民加拿大亚伯达省的卡加利，翌年一家迁到安大略省彼德堡市居住，第三年再迁到卑诗省的温哥华落地生根。在温哥华东区长大，是家中四个孩子之中的老大。
他在查尔斯塔珀爵士中学念中学，并在1978年中学毕业。


== 加入警队 ==
1978年中学毕业后，朱小荪进入西门菲沙大学就读。但由于经济问题，只读了一个学期就休学。
1979年5月他加入了温哥华警察局的警队并成为了一名普通警员（Constable）。在当时，全个温哥华警队就只有3名华人，朱小荪是其中一人。


== 重回校园 ==
1983年，有了4年工作基础的朱小荪再回到校园。在西门菲沙大学半工读，修读工商管理学士夜间兼读课程。
1986年又在卑诗大学修读工商管理硕士MBA夜间兼读课程。并且毕业。因为其警员身份，在学校里他也是一位警方联络员，也曾参与一警方的计划和联络工作。


== 屡被晋升 ==

1989年，朱小荪被晋升为高级警员（Corporal），在911报案中心当班。
1990年获得晋升警官（Detective），被安排在有组织罪案调查科工作。
1989-91年连升3级。在期间他通过了美国联邦调查局特种武器和战术部队的训练。
1991年已晋升为警长（Sergeant），于巡逻小队工作了5年。
1996年转为招募部警长，负责招聘警员。其间他创作并推出了第一个温哥华警察局的网页。
1997年6月再升为督察（Inspector）, 转到执行当值部门。
1998被委派负责E-Comm计划（electronic communications technology），成为当时的策划经理（Vancouver Police Project Manager）。
1999年，朱获得由「卑诗图书馆理事恊会」（The British Columbia Library Trustees Association）颁授之「最佳理事奖」（Super Trustee award）。
2001年成为温哥华市第四区（温哥华西南角，quarter of Vancouver）的区域指挥官（District Commander）。同年他出版了自己赞写的一本英文书《Law Enforcement Information Technology》。 
2003年成为了温哥华警察局副局长（Deputy Chief Constable），负责人事和人力资源部门，掌管资讯科技和社区计划的工作。
2007年5月在渥太华，朱小荪获得由加拿大总督庄美楷颁授的警务功绩勋衔
2007年6月21日，朱小荪被正式委任为温哥华警察局局长（Chief Constable of Vancouver），接替退休的前局长杰米·葛理翰。
2007年7月，朱被指派管理业务支援部门（Operations Support division）、海外罪案情报科（Oversees criminal intelligence）、紧急事故及有组织罪案调查课（emergency response and the gang and drug squads）。
2007年8月15日，朱小荪正式上任温哥华警察局局长。是歴史上温哥华以及加拿大首位的华人警察局长。


== 寻根之旅 ==
自从3岁离开中国后，朱小荪在2009年4月底到5月初首次和家人一道前往故乡上海访问寻根。重游父亲当年经营的书店铺旧建筑，感触良多。朱小荪此行属半公半私，也顺道到北京拜访中国国际刑警。


== 仕途 ==
朱小荪接近30年的警员生涯，一共晋升了8级：

1979年—普通警员（Constable）
1989年—高级警员（Corporal）
1990年—警官（Detective）
1991年—警长（Sergeant）
1997年—督察（Inspector）
2001年—区域指挥官（District Commander）
2003年—副局长（Deputy Chief Constable）
2007年—局长（Chief Constable）


== 奖项 ==
1999年--《最佳理事奖》（Super Trustee award），由《卑诗图书馆理事恊会》（The British Columbia Library Trustees Association）颁授。
2007年5月--《警务功绩勋衔》（the Order of Merit of Police Forces）勋衔，由加拿大总督庄美楷颁授。
