拉米夫定/齐多夫定

拉米夫定/齐多夫定（INN:lamivudine/zidovudine），以商品名称Combivir等于市面上销售，是一种固定剂量的复方抗反转录病毒药物，用于治疗爱滋病。它包含两种抗反转录病毒药物：拉米夫定和齐多夫定。它通常与其他抗反转录病毒药物一起使用。
给药方式为每日口服两次。
个体使用后常见的副作用有头痛、疲劳、恶心、腹泻和发烧。严重的副作用有骨髓抑制、肌肉损伤、先前感染的B型肝炎恶化、乳酸性酸中毒和肝脏肿大。此药物是推荐给个体于怀孕期间用作治疗的一种药物，对所怀胎儿似乎无安全上顾虑。这两种药物都属于核苷类反转录酶抑制剂 (NRTI) 。它们以阻断病毒复制所需的酶 - 反转录酶的活性而发挥治疗作用。
拉米夫定/齐多夫定于1997年在美国获准用于医疗用途，并于1998年在欧盟获准用于医疗用途。它已列入世界卫生组织基本药物标准清单之中。市面上有其通用名药物（学名药）贩售。


== 医疗用途 ==
此药物适于与另一种抗反转录病毒药物合并使用，以治疗人类免疫缺陷病毒第一型（HIV-1）感染。


=== 怀孕期间使用 ===
拉米夫定/齐多夫在美国定被归类为妊娠C级药物，表示怀孕期间使用可能对胎儿有潜在风险，但潜在益处会大于风险。然而已有数据支持此组合在怀孕期间使用的安全性，且在怀孕期间使用通常会优于其他固定剂量的复方药。


== 副作用 ==
拉米夫定/齐多夫最常见的不良反应与其他核苷类NRTI相似，有头痛、嗜中性白血球低下症、贫血、恶心、呕吐、肌肉损伤和指甲色素沉著。报告中所列更严重且可能危及生命的不良反应有伴有脂肪肝的乳酸中毒，但这种罕见的不良事件主要与齐多夫定有关。[由于拉米夫定在低剂量时也具有抗B型肝炎病毒的作用，因此，同时感染HIV和B型肝炎的患者在服用拉米夫定/齐多夫定时，不应擅自突然停药。否则可能会因为缺乏对B型肝炎病毒的持续控制而导致肝炎发作。


== 交互作用 ==


=== 药物交互作用 ===
当拉米夫定/齐多夫定与司他夫定或地西他滨同时使用时，它们会在细胞内竞争相同的活化途径，导致彼此的磷酸化过程受到抑制，进而有降低药效的可能。此外，拉米夫定/齐多夫定也可能与具有肾毒性或骨髓抑制作用的药物（例如阿霉素）产生交互作用，而会增加齐多夫定引起的血液学毒性（如血球数量异常）的风险。因此在使用这些药物组合时，建议监测患者的肾脏功能和进行血液学检查，用以评估潜在的交互作用。


=== 药物-食物交互作用 ===
于服用药物，而同时进食不会影响拉米夫定/齐多夫定的生物半衰期。虽然人体吸收速率会因而减缓，但影响在临床上并不显著，因此，拉米夫定/齐多夫定可随餐或是空腹时服用。


== 作用机转 ==
此复方药由两种核苷酸反转录酶抑制剂 (NRTIs) 组成。
两种成分通过竞争性抑制HIV反转录酶 (RT) 的活性来发挥抗病毒作用，进而降低体内HIV病毒的载量。这两种药物在体内会被宿主细胞的核苷激酶磷酸化，转化为活性形式的5'-三磷酸盐。这些活性代谢物作为病毒DNA合成的底物类似物，能够与正常的核苷三磷酸竞争，并被整合到新生的病毒DNA链中。一旦整合，由于其结构的特殊性，会导致病毒DNA链的延伸中断，从而阻止病毒基因组的复制。
使用拉米夫定/齐多夫定的联合疗法被认为具有协同作用，可共同阻止HIV病毒产生突变，而这些突变可能会导致生成药物抗药性。


== 药物动力学 ==
拉米夫定容易被人体吸收，并广泛分布于血管外空间。口服给药的生物利用度大于80%，整体代谢不显著，约95%的药物以原形经尿液排泄。在人体内唯一已知的代谢物是反式亚砜。拉米夫定的生物半衰期为10至15小时，且与血浆蛋白的结合率很低。
齐多夫定也容易被人体吸收，并且能穿透到脑脊髓液中。口服给药的生物利用度为75%，主要在肝脏通过葡萄糖醛酸化代谢。主要的代谢物是GZDV（3'-azido-3'-deoxy-5'-O-β-D-glucopyranuronosylthymidine），这是一种经过首渡效应后产生的无活性代谢物。齐多夫定的生物半衰期为0.5至3小时，且与血浆蛋白的结合率很低。
拉米夫定/齐多夫定并非主要经由细胞色素P450肝酶代谢。


== 历史 ==
拉米夫定/齐多夫定以商品名称Combivir于1997年获得美国食品药物管理局（FDA）批准，是首个固定剂量的抗HIV复方药物，因此在HIV治疗史上具有重要意义。它迅速成为初治患者的首选RTI，并因其良好的人体耐受性和较低的毒性，被视为治疗的黄金标准，让HIV治疗进入一个新的时代。
相较之下，当时单独使用齐多夫定（AZT）疗法常会伴随令人不适的副作用，而单独使用司他夫定则容易导致患者出现脸部和脂肪萎缩等明显的不良反应。Combivir尤其是在副作用方面，展现出明显的优势。


== 社会与文化 ==
拉米夫定/齐多夫定已列入世界卫生组织基本药物清单之中。
