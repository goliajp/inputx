西莒岛

西莒岛，又称西犬岛（马祖闽东语拼音：Sa-khīng-tō），为中华民国的一座岛屿，位于台湾海峡正北方，闽江口东南侧，其与东莒岛等岛屿组成了白犬列岛。岛屿行政区划上原属于中华民国福建省长乐县，1956年被划入同省连江县西犬乡，1970年以后为莒光乡公所驻地，有青帆、西坵、田沃3村，但中华人民共和国认为此岛是福州市长乐区的外围岛屿。保留大量战地遗构与传统闽东石屋，是马祖地区重要的文化景观岛屿。


== 地理 ==
西莒岛面积约2.34平方公里，地势起伏相较东莒较缓，沿岸多岩岸地形。位于东莒以西约3公里，岛屿周边散布多处小岛礁，如菜埔澳一带渔场资源丰富。岛上水资源缺乏，土壤表层带泥沙，黏性不强，没有河流，主要依靠菜埔沃水库等人造湖泊、水井、以及收集雨水当作生活用水。
因军事因素，包括西莒岛在内的莒光乡全境在Google地图上均会出现道路与景点标示偏移状况，外来游客容易因此迷路。


== 历史 ==
在清以前，西莒岛为渔民停泊与处理渔获的场域。清领时期开始形成聚落。明清时期，因为当局多次将岛上住民向内陆迁徙，西莒岛多次荒废，变成海盗的盘踞地。
在中国抗日战争期间，日本曾在包括西莒在内的白犬列岛扶植建立福建和平救国军，直到后者于1945年5月向国民政府归顺为止。1949年后，福建省海上保安第一纵队进驻西莒岛，该岛亦因战略位置，被中华民国政府划为前线基地，兴建大量军事设施，中华民国国军东海部队和美国西方公司戍扎期间，西莒商贸地位一度加强，并曾被称为「小香港」。1953年9月，长乐县在西莒岛恢复设治。1956年7月，战地政务实施后，第一行政督察区及长乐县裁撤，白犬镇改由连江县代管，并改名为西犬乡。
1960年9月，东犬、西犬二乡合并为白犬乡。1971年11月，中华民国政府将白犬乡更名莒光乡，以示毋忘在莒，西犬岛因此更名为西莒岛。
1992年解除战地政务后，岛上的聚落与军事遗构逐渐成为文化旅游资源。但作为国共对抗的前沿地带，西莒、东莒二岛仍有中华民国陆军马祖防卫指挥部莒光守备大队驻守。1996年台湾海峡飞弹危机期间，因资讯封闭，西莒曾发生恐慌、银行挤兑、民众离开岛屿。


== 交通 ==
西莒岛联外交通不便，主要仰赖水路，由南竿、莒光对开的交通船连结莒光及外界。而西莒与邻近的东莒则有对开交通船。岛上还设有直升机场，有固定航班往来马祖南竿机场，岛上的重症病患也多依靠直升机运送至本岛。
岛内道路联络西坵、坤坵与各景点。西莒之公车固定时刻行驶为交通部公路总局公路公共运输服务升级计划下的幸福巴士，委由连江县公共汽车管理处、连江县交通旅游局、连江县莒光乡公所辅导营运，车型主为8人座中华三菱得利卡厢型车，其始迄站均为青帆的莒光乡公所站。


== 产业 ==
主要产业包括渔业、观光与小型商业。随军事遗址再生，观光比重增加。
