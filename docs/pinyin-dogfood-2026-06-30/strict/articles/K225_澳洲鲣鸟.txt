澳洲鲣鸟

澳洲鲣鸟（学名：Morus serrator；毛利语：tākapu或tākupu），又称澳纽鲣鸟，是鲣鸟目鲣鸟科的一种大型海鸟。 成鸟大部分为白色羽毛，沿著翅膀后端的飞羽及中央尾羽为黑色。亚成鸟的头部是白色羽毛带棕色斑点、而身体则相反，为棕色羽毛夹杂白色斑点；出生不久的雏鸟则覆满白色绒毛。
澳洲鲣鸟主要栖息于海洋及海岛环境中，其中部分个体有来往于澳洲及纽西兰之间的迁徙行为。鲣鸟于澳洲东南部和纽西兰离岸岛屿的悬崖、海岸上筑巢繁殖，如维多利亚州、塔斯马尼亚以及北岛等地。为肉食性，以潜水猎鱼为生，主食为远东拟沙丁鱼，但其他小型鱼类或者头足类也可以作为选项。一般预期寿命约为20年，四至七岁时会开始繁殖。繁殖季时具有领域性，并有求偶等社交行为，行一夫一妻制。配对后，每次产一颗蛋，并筑土丘状的巢，由雌鸟孵蛋并由双亲照顾至离巢。
牠们的族群正在持续增长，且面临的生存威胁——如商业捕鱼、捕食者等——并不多，因此被国际自然保护联盟评为无危。


== 物种命名 ==
其最早的相关纪录在1769年12月24日，当时约瑟夫·班克斯、丹尼尔·索兰德与作为素描家的西德尼·帕金森伴随詹姆士·库克船长第一次出航至太平洋地区，班克斯于三王群岛射杀了数只澳洲鲣鸟，作成鹅肉派供其属下水手作为隔日的圣诞节餐点。帕金森随后留下了关于此种鸟类的画像，并在下方注记了Pelecanus sectator此一名称。索兰德同样也文字正式纪录了这种鸟，并发现与已知的北方鲣鸟有所不同的特征，而命名Pelecanus chrysocephalus，随后也改为Pelecanus sectator。
1841年，约翰·古尔德将在塔斯马尼亚的德文特河和阿克泰翁岛所发现的同一种鸟类的标本取名为Sula australis，但当时詹姆斯·斯提芬斯早已使用该名称命名红脚鲣鸟。英国动物学家乔治·罗伯特·格雷参考了古尔德的相关描述，于1843年正式发表了该物种。格雷最初使用古尔德所命名的S. australis，但在两年后发现该命名无效后，便根据帕金森跟班克斯先前的报告改用了S. sectator，却意外拼错成为S. serrator并沿用了此一名称。古尔德当时虽坚持使用S. australis作为名称，但最后同时期的作家们仍更常使用S. serrator，遂成为正式的名称。
Morus源自古希腊语μωρός（希腊文拉丁转写：Moros），意为愚蠢、愚笨，，衍伸自繁殖期的鲣鸟科成员缺乏戒心而容易被杀死之故。种小名serrator可被翻译为“sawyer”，源自拉丁文serra，锯子之意，与其锯齿状的喙部有关。
世界鸟类学家联合会指定「澳洲鲣鸟（Australasian gannet）」为该物种的正式通用名称，太平洋鲣鸟（Pacific gannet）也是其通称。在澳洲有澳大利亚塘鹅、潜水者（来自鲣鸟冲入水中的动作）、鲣鸟或索兰鹅（solan goose）等称呼。
鲣鸟科约于3000万年前分化，早期演化的物种较接近鲣鸟的大小。目前认为现存最古老的鲣鸟是做为阿波特鲣鸟属唯一种的粉嘴鲣鸟。约1600万年前，大鲣鸟属开始分化出来并将原本在北半球的栖地渐移至南半球，成为了现今的分布情形。当前的大鲣鸟祖先大约在250万年前出现，分裂为北方和南方两支系。南方支系更进一步于约50万年前分裂成了位于好望角的南非鲣鸟和澳洲鲣鸟。这几种鲣鸟曾经被归于北方鲣鸟的亚种，但现今认为是形成复合种的不同物种。澳洲鲣鸟独立后曾被认为有两个亚种，分别是位于纽西兰的S. serrator serrator以及在塔斯马尼亚岛上的S. serrator dyotti，但现已取消该分类。


== 形态描述 ==
成鸟平均体重约2300公克，体长84—91公分，翼长170—200公分之间，嘴峰长约88.3公分，喙宽度约22.4—2.51公分之间、厚度约9.15公分，跗跖长约54.1公分，尾长约19.5—20.5公分之间。雌雄个体之间差异并不大，但雌鸟的体重比雄鸟稍重，翼展及喙长也稍大。

澳洲鲣鸟有著典型的鲣鸟科特征：具有黑白色羽毛的大型海鸟，尖喙以及尖尾巴。成鸟主要为白色的羽毛，黑色的飞羽列于翅膀后，中央尾羽也为黑色，并具有明显的深浅分界，部分个体的黑色尾羽范围可能会更大。后颈有一淡黄色斑块，繁殖季时颜色会更明显。眼周有一圈蓝色的眼环，灰色虹膜。鸟喙为珍珠灰色，边缘带有深灰色或黑色，上喙沿著交界有一条黑色凹槽。腿及脚呈灰棕色，脚背和脚趾上则有鲜明的黄色或绿色条纹，脚趾间则有类似脚部颜色的薄膜连接。亚成体头部有白色带棕色斑点的羽毛，而冠羽、肩、背、臀部为偏浅褐色至灰褐色羽毛，带有白点，下巴至腹部则有接近成鸟的白色羽毛，带有部分棕色的边缘，约2—5年后会换羽为成鸟的白色羽毛。

澳洲鲣鸟之大小外观与北方鲣鸟以及南非鲣鸟类似而易于混淆，但通常能用尾羽的黑色羽毛分布状况区分：北方鲣鸟尾羽通常全白，而南非鲣鸟通常全黑或大部份为黑色，但并非澳洲鲣鸟那种对称的黑白羽毛——通常澳洲鲣鸟只有四片中央尾羽会是黑色的，且南非鲣鸟的喉部条纹也长于澳洲鲣鸟至少3倍。行为跟叫声也有所不同，亚成鸟也只有澳洲鲣鸟会有斑驳的棕褐色。


=== 叫声 ===

相较于其安静的海上飞行，当澳洲鲣鸟进入繁殖季时，牠们在白天及部分夜晚时段时会在栖地中大声喧哗。叫声具有个体差异，通常雌性会比雄性来的低一些，会在快到达栖地时或是做为威胁时发出类似「啊啦啦、啊啦啦（arrah-arrah）」的声音。


== 分布 ==
澳洲鲣鸟是部分迁徙的鸟类，栖息在开放的海洋及海岛环境中，主要分布于在澳洲东南部海岸、塔斯马尼亚岛、纽西兰及其它邻近的一些小岛上。在海上，牠们通常不会飞离远于大陆架水域，在暴风雨时可能会进入海湾、港口和河口躲避。在五至六月时，纽西兰的年轻鲣鸟们会朝北和西方移动，主要是向北飞行到北岛，部分鲣鸟也会选择通过库克海峡，并飞到昆士兰东南部和西澳的罗特尼斯岛停留。部分鲣鸟会到南印度洋的马里昂岛和克罗泽岛，甚至有曾经飞抵南非与南非鲣鸟交配的纪录。但相较于在澳洲的水域停留三到四年后才回到纽西兰的个体，也有些会直接留在纽西兰的水域生活。


=== 繁殖地 ===

澳洲鲣鸟的繁殖地大部分分布于离岸岛屿上但澳洲和纽西兰等相对大的陆块也有几个繁殖点，这可能是受限于繁殖点空间有限而外溢到陆地上的结果，但都会受到海水温度高低所带来鱼类多寡影响。自1950年的调查以来，澳洲和纽西兰繁殖点的数量互有消长：在1980—2000年期间，在澳洲的繁殖对数从约6600对增加到20000对。纽西兰在1981年展开的全面调查显示约有46600对，到了2006年，估计已增加到约55000对。
在维多利亚州，鲣鸟有邻近波特兰的劳伦斯岩、位于墨尔本附近的教皇之眼跟楔型沙洲灯塔（Wedge Light）附近的繁殖点。劳伦斯岩的繁殖点对数于1873年的200对增加至1996-1997年的约3100对，到了此时岛上已无再增长的空间。1995年，鲣鸟在附近的陆地危险角停留，并在人类筑起一道防狐狸栅栏后，于隔年开始在此繁殖。危险角作为澳洲大陆上唯一的繁殖地点，繁殖对数正稳定增长，于1999-2000年达到660对。菲利普港湾中的人造结构在1966年开始有繁殖的纪录，楔型沙洲上当时有三对。到了1999—2000年，已有507对于此地繁殖。
在塔斯马尼亚州，鲣鸟有数个繁殖地，包含南岸的埃迪斯通、白岩，在佛林德斯岛南边的猫岛和西北岸的黑锥岩。黑锥岩的繁殖对数从1961年的500对增加到1998年的12300对，埃迪斯通在1947年的20对增加到1998年的189对，而白岩在1939年的1000对增加到1995年的3300对，但这些地点已经几乎没有扩张空间。相对地，在猫岛由于掠食动物捕食，繁殖对数从1908年估计5000—10000对下降至2000年后几乎寥寥可数的数量。
在纽西兰，几乎所有的繁殖地都在北岛上或该岛周围，例如卡维亚岛在詹姆士·库克船长于1770年1月发现该岛时，因岛上有鲣鸟栖息而命名为“鲣鸟岛”（Gannet Island），在1981年的调查显示该岛有8003对鲣鸟。位于雷恩加角西北55公里处的三王群岛，为纽西兰最大的离岸鲣鸟繁殖地，1981年有9855对鲣鸟分布其下五个较小的繁殖地，2014—2015年的空中调查发现该繁殖地的数量减少至6402对。位于丰盛湾外48公里处的怀特岛，也由五个较小的繁殖地组成，1980—1981年有6662对，2014—2015年减少至5306对。位于豪克斯湾的拐子角繁殖地最早于1850年左右有鲣鸟定居的纪录，1885年报告有100对，1981年的调查显示有5186对。位于奥克兰附近的穆里怀海滩，包含奥卡塔米罗角（Okatamiro Point）的本土繁殖地于2016年估计有1385对，以及附近的莫图塔拉（Motutara / Pillar Rock）有187对。2007年，鲣鸟在岛湾九针石（Tikitiki Rock / Nine Pin Rock）建立了一个繁殖地，到2017年左右已经有约70对鲣鸟。在2008年，牠们也开始在杨尼克角建立了一个小型繁殖地。
在繁殖地相对较少的南岛，鲣鸟于1983年开始在道别角的尽头繁殖，该地区称为贝壳岸（Shellbanks），是一个由贝壳、漂木组成，夹杂著数种低矮的植被：如欧洲海滨草、海滨芥、苦茄和苦菜等，约2公尺宽的区域。该地点提供了适当的条件让鲣鸟繁殖：强风使其大多能够近乎垂直的起飞，同时邻近商业捕鱼量的下降——含金湾和塔斯曼湾等地——也导致食物供应的增加，涨潮会分离该栖地以及本岛，但暴风雨的影响会是一个推力因素。数量每年增长约11％，2011年估计有3900对鲣鸟。在福沃海峡的小索兰德岛上，有纽西兰最南端的鲣鸟繁殖地，1948—1986年间记录了大约20对鲣鸟的到来，有一次较为特殊的纪录是在1984年记录了62对鸟，但原因不明。


== 习性 ==
澳洲鲣鸟在海上通常是独来独往的，但一旦发现可以狩猎到可作为食物的鱼，其他的鲣鸟就会加入行列并形成一个鸟群。在陆地，牠们是群居的。非繁殖期的鲣鸟通常会聚集在群居地的外围形成一些小群。少量鲣鸟可能会在繁殖季结束后留在群居地周围，作为栖息地。


=== 繁殖 ===
澳洲鲣鸟通常为一夫一妻制，且持续时间较长，有些对偶可能会一起繁殖好几季，直到其中一只死亡，但有被观察到会结束双方关系的情形。在繁殖时期，鲣鸟会有更为明显的领域性，会以激烈的敌对行为来标示自己的领域，以防止邻居和其他闯入者的入侵，且通常雄性会比雌性有更多的领域行为。在宣示领域或想威胁入侵者时，鲣鸟会将翅膀张开，喙朝空中，甩动头部，并辅以大声叫喊的行为。此动作会重复数次，并让邻近的其他鲣鸟也会容易也做出同样的动作。而攻击的行为分为数种：一种是闭上嘴对著其他鸟冲刺；一种是开嘴咬住对方；最后一种则是双方继续进行长时间的交嘴搏斗。这些打斗行为的比例取决于是否为繁殖季，且最严重者可能致命。当降落在鸟群中或者是想降低其他鲣鸟的攻击行为时，会以低头和收起喙的方式示意给其他同伴。

成功配对的鲣鸟会在雄鸟回到巢时以喙做出类似剑击的求偶行为。两只鸟胸贴胸，展开翅膀，喙向上伸出，快速地互相交叉敲击对方的喙，同时大声发出叫声，这种类似击剑的动作有时会穿插著鞠躬的动作，且通常在交流之后互相梳理羽毛。成对的鸟还会进行指向天空（Sky-pointing）的行为，一只鸟缓慢地步行，颈部和嘴巴垂直，翅膀部分举起。在相互梳理羽毛之后有时就会交配：此时母鸟会坐回巢内猛力摇头，雄鸟咬住她的颈部，爬上背部，挥动翅膀，然后和母鸟交配。交配后，雄鸟从伴侣身上滑下，并互相理毛。这些事件的频率会随著产卵日的逼近到甚至到当天都有可能发生，发生机率也会随之增高。
繁殖季通常是七月到二月之间，不同地点之间会有不小差异。在莫图卡瓦奥岛岛上，鲣鸟在六月中旬回岛，7月20日至8月7日之间下蛋。幼鸟从10月10日到11月2日孵化，从12月底开始长出完整翅膀。在拐子角，鲣鸟会在七月底返回该地，在九月初到十月底之间下蛋。幼鸟在二月初开始长出可飞行的翅膀。在教皇之眼，鲣鸟在8月初至12月之间下蛋，其中位数和平均值是在9月。年轻鲣鸟通常比相对老的晚一些下蛋。繁殖日的变化比北方鲣鸟更大，可能是由于季节天气变化相对不剧烈，造成繁殖季节有过大限制所致。
澳洲鲣鸟偏好的建巢地点有介于海拔15—90公尺之间的离岸岛屿石堆、平坦地面、缓坡或者阶梯状的地形上。一般为裸露的岩石或长有低矮灌木的地面，如臭叶木、松叶菊、须尾草或其他草本植物等。其巢穴形状是杯状土丘，土丘高约10—20公分、中间的孔洞深约30公分，由海藻、植物、泥土和海洋碎屑组成。通常是雄鸟收集材料并交给雌鸟，然后由雌鸟建造巢穴。鲣鸟每次只产下一颗蛋，重量可在84—125公克之间，平均为99.8公克。


=== 成长 ===
卵呈浅蓝色、长椭圆形，长为65—89公分，宽为35—53公分。蛋表面在干燥时会褪色成白色，并有会粉末般的表面触感。通常每个季节只会孵化一次，但如果蛋丢失或不足八天的幼鸟死亡，父母常常会重新孵一颗蛋。孵化期需要37—50天，主要由雌鸟负责，用其蹼足保暖。

新孵化的雏鸟只有稀疏的新羽，皮肤为黑色，出生后2—3天眼睛才睁开。白色的绒毛会在约2周大时长出，并在4周大左右时长齐。第43—47天大时会开始长出飞羽，到了9周大时，大约有一半会换成羽毛，并在13周大时完全褪去绒毛。年幼的雏鸟由父母鸟喂食半消化的鱼肉，双亲会张开嘴巴以不完全的反刍让幼鸟取食。
雏鸟约在孵化后第95—109天羽翼丰满，牠们会走到附近的悬崖顶上，在那里停留6小时—3天不等，然后开始飞行。牠们出生时平均重73.2公克，到了第50天时体重已经达到2350公克，第90天时已经达到3132公克，甚至可超过成年鸟的体重。澳洲鲣鸟的雏鸟在离巢时就已经飞羽已经发育完全且能飞行，与北方鲣鸟不同。
年轻的成鸟会在三岁时回到鸟群中，四至七岁开始繁殖，一般预期寿命约为20年。目前有纪录最长寿的鲣鸟是在澳洲昆士兰州天阁露玛的摩顿湾被发现的，原标记地在拐子角，死亡时已距离标记时间30年又8.2个月，两地距离约为2587公里。而移动距离最远的纪录是约8128公里，在模里西斯东南边海滩上被发现的已死鲣鸟，原标记地位于劳伦斯岩。


=== 食性 ===
澳洲鲣鸟为肉食性，主要食物来源是小型鱼等水生动物，有时也会参杂头足类。牠们有著惊人的潜水能力，可从20公尺高的地方冲进海中深潜，也可在1—3公尺深的浅水区捕食。可以在恶劣天气中在浅水区捕食，但一般不太会在强风的状况下如此。根据观察，在道别角的鲣鸟主要在水深不到50公尺的沿岸捕食鱼类，而在拐子角的鲣鸟则偏好在深度超过50公尺的深海中捕食鱼类。这些鲣鸟有时也是机会主义者，会跟随渔船和拖网渔船，捡拾被弃置的鱼类食用。由于其体型较大而不能持续在空中盘旋，但牠们可以短暂停下以观察海面上的鱼况。
由于远东拟沙丁鱼提供了高热量，是澳洲鲣鸟的理想食物来源。但是沙丁鱼的数量会受环境影响并不稳定，如鱼群在1995年因疱疹病毒侵袭而大量死亡之后，澳洲鲣鸟1996年在道别角改为食用澳洲鳀鱼，以及在1998年在菲利普港的杖蛇鲭来因应。但食用澳洲鳀鱼的问题是热量较少，鲣鸟常常需要食用更多的鳀鱼以维持同等摄入的热量。这种需要花费更多力气捕鱼的状况可能会进而影响了繁殖率。1995年，巡逻员在奥克兰西部和北部的海滩上发现了648只死去的鲣鸟，1995年的沙丁鱼死亡事件和7、8月的异常强烈的西风和西南风被认为是可能的因素，但确切原因仍不明。
其他纪录有食用纪录的鱼类包括鳟澳鲈、福氏厚唇鲻、小眼澳鲈、谐鱼、青背竹䇲鱼、纽西兰竹䇲鱼、婢䱵、蓝背黍鲱以及须唇飞鱼属、文鳐鱼属的飞鱼。头足类的双柔鱼属也是鲣鸟的食物。


== 天敌与威胁 ==
有记录指出巨鹱会将成年澳洲鲣鸟沉在水下将其淹死以当作食物。黑背鸥和太平洋鸥也可能会干扰亲鸟迫使牠们放弃其蛋和雏鸟，使之成为前两者的食物。
澳洲鲣鸟也会受到部分外来寄生虫困扰，包含从被作为博物馆鲣鸟标本后从中搜集到的Morinyssus simplex、Pectinopygus bassani和硬蜱属下的Ixodes eudyptidis、Ixodes uriae和软蜱科下的Carios capensis。


== 保护状况 ==
国际自然保护联盟目前将澳洲鲣鸟列为无危物种，因为牠们的族群很大且可能正持续增长中。虽然商业捕鱼以及捕鸟用作鱼饵的行为可能对其数量产生影响，且鸟蛋容易受到油污染影响而无法孵化，但相对于其他海鸟而言，影响可能较低。每个繁殖季节的雏鸟生存率会因食物供应和天气等因素而有很大的变化。现今比往常更加频繁的圣婴-南方振荡现象导致巴斯海峡的水温升高，从而产生更多的鱼类聚集并使鲣鸟的族群随之增加。自1980年以来，整体族群的年增率约为6%。
2008年9月，环境保护团体在吉斯伯恩附近的杨尼克角以放置假鸟巢和播放预录鸟叫声的方式，吸引了澳洲鲣鸟建立了一块栖息地。从2010—2011年的繁殖季起，开始得到了成功的繁殖纪录。类似的努力也发生在玛纳岛，环境保护团体在该岛西岸架设了80只水泥制的澳洲鲣鸟，并拨放其叫声，使一只孤独的后来被命名为“单身鸟奈吉尔”的鲣鸟于2013年到达该地生活了数年，直到2018年被发现死亡；在2017年末，另外三只鲣鸟抵达了该地生活。2010年，在纽西兰莫托拉岛的保护区，也利用了类似手段建立了鲣鸟的繁殖地，并留下成功繁殖的纪录。


== 与人类的关系 ==
毛利人会在三月份时至卡维亚岛捕捉澳洲鲣鸟的幼鸟做为食物。成年鲣鸟的白色羽毛会被用来装饰独木舟，或者由部落内的较高阶级的成员佩戴。而骨头会被制成工具，用以制作脸上的刺青。
部分鲣鸟栖息地已成为旅游景点，例如拐子角、纽西兰的穆里怀海滩，和澳洲波特兰的危险角各自有数百至数千对鲣鸟在该地繁殖。而1958年和2009年发行的纽西兰邮票上也有拐子角鲣鸟的图样。
