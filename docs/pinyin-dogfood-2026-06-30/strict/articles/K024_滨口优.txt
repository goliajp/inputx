滨口优

滨口优（日语：滨口 优／はまぐち まさる，罗马化：Hamaguchi Masaru，1972年1月29日—），出身于日本大阪府大阪市此花区；是好孩子（よゐこ）的其中一员，搭挡是有野晋哉。1990年入社，所属经纪松竹艺能。
由于台湾国兴卫视曾播出黄金传说节目，因其热血与豪迈的演出，在台湾也有一定人气与知名度，成为熟知的搞笑艺人。


== 简介 ==
家族成员有祖母、父亲、母亲、二位弟弟，祖父是渔夫、祖母是海女。弟弟滨口秀二是演剧的演员，有演一部在地方深夜节目很有名的KBS京都の「谷口な夜」。
兴趣是线上游戏。自从松竹艺能的师弟搞笑团体アメリカザリガニ，送给滨口XBOX360之后滨口就爱上了玩线上游戏。2007年的私人的东京游戏秀，在舞台上被水桥博士发现他参加Halo 3艺人 VS 演员的比赛活动。
讨厌香烟。将香烟的内容物更换成咖哩粉代替了烟丝来吸食。
爱车是标致Peugeot 206。令人意外的是之前的车子是porsche 930型。
从小学以来一直在收集金肉人橡皮擦。CS特别针对「喔!这个企划案」详细的解说全系列418个身体。虽然无法想起电影超人原作的名字，但滨口发挥他的想像力当场随便乱命名，让平常对漫画、卡通颇了解的有野露出吃惊的表情。
兴趣是看成人影片，以前一周就买两部成人影片，后来购入了50吋液晶电视还使用了卫星电视「SKY PerfecTV!」的付费频道「樱桃炸弹」(成人影片频道名)，现在是24小时AV自由看。
没看AV的时候，当众说出妄想杉本彩的话。而且如果只有妄想并不构成犯罪。
滨口在共同演出的「イケ」时当众声明「如果演员界的黄帝是泽村一树的话，那我就是搞笑界的黄帝。」
流行感也很好，但曾被冈村隆史认为「不擅于打扮」。并且也被叫做「自慰伯爵」。
被有野晋哉笑过几次「会一直秃头下去」滨口总是只有回瞪他。于是他跑去美容院做头皮查询，原来会掉发的原因是毛孔阻塞，于是使用了化妆师所推荐一瓶一万日圆的洗发精，结果效果非常好，从一个毛孔只长一根头发到可以长三根头发，于是「毛发丛生」的现象开始出现了。这件事情，滨口本人在MBSラジオ『ゴチャ・まぜっ!』（金スペ）的广播节目中有谈到，旁边的成员伊崎右典(FLAME)说也仅仅只是头发开始增加而已。
本人长的和日本职棒「横滨海湾之星」的二垒手仁志敏久有几分神似，大家都说滨口是「不会打棒球的仁志」。同时，滨口和仁志敏久也是同届的同学。
和晚辈艺人一同组成「松竹电影同好会」，大家开始以「队长」称呼他，欣赏的电影类型主要是动作片，几乎不看爱情片。电影同好会的成员有：木下隆行（TKO）・平井善之（アメリカザリガニ）・Over Drive绪方・还有松竹艺能事务所的竹下经理。
在黄金传说的清理垃圾屋企划中，清理垃圾，了解并诚心帮助屋主。
在黄金传说中，于青森县大户濑渔港用一只鱼叉捕获40kg的巨大章鱼。
在黄金传说中，他自己向节目主持人报名（不是被邀请的），曾经在2001年11月1日挑战过一星期吃完1000个仙贝（日语：煎饼）的传说，但最后却在第825个时未在时间内完成而失败。（该项传说后来在2007年由小崇小敏两人挑战完成），该挑战一个月（2001年12月27日）后，挑战一星期吃完1000个干货的传说，虽然在吃第153个时吃到牙齿掉了一颗，但最后还是成功达成传说，在完成传说时，他边笑边表示自己有点小感动，「不过只是吃完干货而已！」。


== 多佛尔海峡 ==
「火焰大对抗」的企划「横越多佛尔海峡」，接受了正规的长泳训练，拥有横越多佛尔海峡的纪录。


== 节约战斗时期 ==
在『黄金传说』中挑战『一万元过一个月的节约生活』单元中，成为固定班底。在节目上挑战过10次，前9次均以失败收场，最后的第10次从一开始一直都是吊车尾到最后以剩下736円终于得到冠军。
第10次挑战中，滨口制作了3个黑暗料理，分别是：人脸关东煮茶碗蒸、关东煮冰棒、情人节甜心饭，节目组让知名主厨坂井宏行试吃后表示人脸关东煮茶碗蒸和情人节甜心饭味道不搭，而关东煮冰棒则是太难吃，节目组在播出前因为这些问题有找滨口讨论，人脸关东煮茶碗蒸和关东煮冰棒最后因为坂井宏行的意见而剪去该片段，至于情人节甜心饭则是因为滨口认为太害羞因此拜托节目组剪去该片段。
第一次参加『一万元过一个月的节约生活』单元时，第一餐却没有像其他艺人一样节省，而是跑去吉野家买牛丼吃。
为了省钱时，会跑到海边去捕鱼，大概是遗传到祖父、祖母的基因，所以潜水技术非常厉害，能在水里捕捞到不少的鱼，偶尔还会捕抓到章鱼。
参加『一万元过一个月的节约生活』时，为了省买鸡蛋的钱，特地跑去买一只母鸡，还帮母鸡命名为『しゃくれ』（戽斗），跟『しゃくれ』一起生活，『しゃくれ』下的每一颗蛋都是非常的珍贵，对节约生活很有帮助，滨口非常的疼爱『しゃくれ』（然而，有网友分析，滨口省下买鸡蛋的钱，但花在戽斗的饲料500円就花的跟鸡蛋差不多了，其实并没有省到甚么钱）。
在料理方面也非常豪迈，常常把捕来的渔获直接放到油锅里炸，不加任何调味料。这也成为滨口自己独特的料理方法。在处理食材、渔获即兴对话，这一特点也是滨口优在该单元中的特点，为他提升不少人气。
在节约单元中，如果滨口有参与演出，收视率将会提升不少。
Kis-My-Ft2的玉森裕太准备挑战『一万元过一个月的节约生活』前，有向滨口请教。（最后玉森裕太以剩下1324円得到冠军）


== 口头禅 ==
在『一万元过一个月的节约生活』和『无人岛0元生活』单元中，每每要是捕获到鱼类或章鱼，上岸后一定会对著大海与天空大声的喊「获ったどー！」（抓到了！）。由于这样的大声呼喊，也得到不错的回响，颇受好评。
也喜欢在作料理时，边作料理边喊自己的名字「まさる！」。和搭挡有野晋哉一起烹煮食物时，也会要求搭挡跟他一起喊「まさる！」。之后在料理时一定必喊「まさる！」。
在作料理时，还会发挥想像力把食材或鱼类，当成是外星人或对抗的对象，与它们对话，完全进入自己的世界，玩的不亦乐乎。

== 游戏软体 ==
「好孩子的搞笑之道～老爹寻找3丁目～」
「好孩子的无人岛生活」
于 2008 年春季推出，改编自日本搞笑团体「好孩子」滨口优与有野晋哉主演的综艺节目「好孩子的无人岛0圆生活」，叙述两人在无人岛上求生的趣事。
游戏中玩家将扮演滨口与有野，为了取得求生所须的物资以及栖身之所而奋战，透过触控笔来进行鱼叉猎鱼、料理食材、收集材料搭建小屋、对抗暴风雨的侵袭....等等。透过两人面对求生考验的种种无厘头反应，让玩家体验如同电视节目原作般的搞笑趣味。另外，朝日电视台也为了滨口优推出许多周边商品如扇子或笔记本与毛巾等。
