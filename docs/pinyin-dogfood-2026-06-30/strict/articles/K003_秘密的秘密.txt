秘密的秘密！

《秘密的秘密！》（日语：ないしょのないしょ！）是Iris在2012年11月30日发售的恋爱冒险类型成人游戏。Android版于2013年7月25日在vamarket上发布。蓝光版在次日开售。
《秘密的秘密！》拥有多条剧情分支路线，每条路线皆有一系列预先设定的场景和人物互动。其主要聚焦于两名女主角跟玩家角色的互动，并刻画了角色之间的性行为。整个故事以主角水梳聪里的视角作切入点。他受继母所托，而要在她出差期间照顾著两位继妹水梳叶月和水梳恋。
《秘密的秘密！》的销量在开售后随即登上日本全国美少女游戏销量排行榜第11位；日本美少女游戏暨动漫相关商品销售网站Getchu屋的最畅销游戏排行榜第13名，在该站亦被票选为2012年11月第10佳的美少女游戏。


== 游戏系统 ==

《秘密的秘密！》采取恋爱冒险的游玩方式，玩家所扮演的是本作的男主角水梳聪里。基本上玩家在游玩的时候都需阅览屏幕上所显示的文本和聆听游戏发出的声音，用以了解故事情节和人物之间的对话。该些文字会与人物拼合图和背景一同出现，用以表示聪里跟谁对话。玩家会在故事中遇见代替背景和人物拼合图的CG。《秘密的秘密！》拥有多条剧情分支路线，每条路线的结局皆有所不同。玩家的选择会影响剧情路线，从而影响之后的结局。
本作角色之间的关系亦带有一定性意味。有关场景包括手交、口交、性交。玩家在某些预设的段落中须选择行为选项。对话框的下一段文本在做出选择前并不能够显示。玩家必须反复载入选项页面并选择不同的选项，才能够观览存于不同路线的剧情。《秘密的秘密！》拥有多个结局。


== 故事 ==
本作的主角水梳聪里是个以绘画绘本来维持生计的画家。他因受到义母所托，而要在她出差期间，照顾着两位继妹水梳叶月和水梳恋的起居。叶月有着灰色头发，性格认真，易害羞。恋则有着金色头发，思想单纯，平日行为多变。在一起同居的情况下，聪里渐渐对上述两位继妹产生性欲，于是便开始与她们进行各式各样的性行为。


== 开发 ==
《秘密的秘密！》是Iris继《暗色的雪花莲群》之后的第2部作品。本作一改前作的黑暗风格，以「治愈」和萝莉角色作主打。曾于《暗色的雪花莲群》负责原画的ふくみみ，再次于《秘密的秘密！》负责以上项目。编剧由绫那和神野诗织共同担当。神野诗织此前曾负责同人成人游戏《あゆみちゃんだいありぃ -白- 》的编剧。绫那则有在前作《暗色的雪花莲群》跟ふくみみ合作的经验。片头曲《ないしょのないしょ!》的主唱者为梨本悠里，片头动画由外包商KIZAWA studio负责制作。片尾曲《Naisho de Funk!》由水梳叶月和水梳恋的声优今谷皆美和shizuku主唱。Meeon负责游戏的配乐。


== 宣传发行 ==
2012年6月，Iris在官网上公开两位女主角的声优和发表声频样本。8月23日，它在Twitter预告晚上会公开本作的片头曲演示影片，次日如期于YouTube上公开。同月31日，它在秋叶原举办本作的宣传活动，参与者可获赠本作的画师所绘制的插画。同日开放给公众预购。10月22日，Iris发布了本作的免费试玩版，予供公众下载试玩。
PC正式版的游戏光碟在2012年11月30日发售，同时相容Windows XP/Vista/7。预订版会附送广播剧CD；初回版则会附送小册子。部分商店会为购买《秘密的秘密！》的顾客赠送像海报、电话卡、挂毯般的赠品。
Android版于2013年7月25日在vamarket上发布。Asoberu! BD-Game（あそべる！ BD-GAME）于4月26日开放给公众预约本作的蓝光版，同年7月26日开售，当中追加了三段剧情。蓝光版开售的当天，下载版亦一并推出。


== 相关产品 ==


=== 画集 ===
初回版附送的小册子共有40页，它收录了本作的原稿及没有采用的插画。2014年11月，Core Magazine发售了一本192页的画集《ないしょのないしょ! &しゅきしゅきだいしゅき!! Irisアートワークス》，其内容包括本作与Iris的另一部作品《しゅきしゅきだいしゅき!!》的游戏插画、设定资料、工作人员采访记录。


=== 广播剧CD ===
预订版会附送以「两位姊妹在聪里手部受伤期间照顾他」的展开为主题的广播剧CD。


=== 抱枕 ===
以本作角色为主题的抱枕套在2013年至2014年期间开放网上预约，于C87上亦有贩售。


=== 原声带 ===
市面亦有发售《秘密的秘密！》的原声带，其包含游戏的片头曲以及片尾曲，并为上述两者附上两位女主角声优的合唱版和独唱版。


== 评价 ==
2012年11月，《秘密的秘密！》的销量在日本全国美少女游戏中排第11位。它在日本美少女游戏暨动漫相关商品销售网站Getchu屋的2012年11月最畅销游戏排行榜上排行第13名，在该站亦被票选为当月第10佳的美少女游戏。
