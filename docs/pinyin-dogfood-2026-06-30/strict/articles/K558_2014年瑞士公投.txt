2014年瑞士公投

瑞士在2014年举行了4次公投，表决12项议题。在2月9日举行的第一次公投中，瑞士选民否决了堕胎费用自理动议，不过他们通过了铁路基建拓展和财政补助动议和限制大规模移民的动议，当中反移民动议令瑞士政府要恢复移民配额制和重启与欧洲联盟（欧盟）之间的人员自由流动谈判，更令欧盟要把瑞士逐出伊拉斯谟计划等科研计划。5月18日第二次公投当中，其中一项表决议题是设立全球最高的最低工资水平，不过这项受到资方反对的动议最终以大比数被否决，而采购JAS 39狮鹫战斗机的计划也以微差告吹。然而，选民仍然通过了保障家庭医生制度和限制恋童癖患者从事儿童相关职业的动议。9月28日第三次公投表决的议题包括设立统一的公共医保制度和调整饮食业增值税税率，11月30日第四次公投表决的议题则包括黄金储备动议（要求瑞士央行拥有一定份额的黄金储备，并将之运回国内储存）、废除外国人缴纳的统一税和限制人口增长。这五项动议最终都被选民一一否决。


== 2月公投 ==
在2月9日举行的公投一共表决了三项议题，包括堕胎费用自理、反大规模移民和铁路网络拓展及财政补助。关于堕胎的议题要求，堕胎费用不再由医疗保险报销，而应该由孕妇自己承担。
反移民动议由瑞士人民党提出，该动议反对瑞士与欧盟签订的劳工自由流动协议，上述协议在2000年公投举行后引入瑞士。
而关于铁路设施扩建和财政补助的联邦决议则要求成立一项专门铁路基建基金，取代当时由联邦和各州政府管理的同类基金。决议也拟定了一项预计在40年内分期实行的铁路拓展策略，该策略将耗资420亿法郎对该国铁路进行改善工程。决议还要求瑞士联邦委员会（瑞士政府）定期向国会回报策略举出的个别项目实行的进展。该策略的第一期计划内容包括加快城际铁路的行车速度和在伯恩、巴塞尔和日内瓦周边进行都市快铁延伸工程。


=== 结果 ===
选前民意调查显示反对这项限制移民措施的选民人数一度领先，不过支持者和反对者的人数差距却在公投日临近之际开始收窄。反大规模移民动议最终以些微差距获得通过，支持率为50.3%，该动议也得到足够州份的通过。这项措施要求瑞士政府在三年内重新展开关于瑞士和欧盟之间的人员自由流动协议的谈判或者废除有关协议，还规定瑞士当局要重新对各类移民设置固定的配额，并限制外国人带家眷到瑞士定居、为他们申请社会福利和庇护的权利。
另外，主张堕胎费用不应由医疗保险垫支的堕胎费用自理动议以大比数被否决，表决这项议题的选民当中约有七成选民投了反对票。反之，关于铁路基建拓展和财政补助的动议则以62%的大比数差距获得通过。


=== 后续事件 ===
由于公投通过了限制移民的动议，因此瑞士无法与克罗地亚签订人员自由流动协议。欧盟因而把瑞士逐出欧洲有史以来规模最大的教研计划伊拉斯谟计划和地平线2020计划，以示还击。


== 5月公投 ==
瑞士在2014年5月18日举行了一次公投，表决4个议题。当中，一项关于最低工资的倡议提议政府推行工资保护措施，按照集体谈判协议制定最低工资，并把全国最低时薪的水平定于22法郎；该倡议一旦通过，瑞士将拥有全球最高的最低工资水平。反对这项提议的资方认为这样做会增加生产成本和失业率，最终该倡议也被七成半选民否决。。另外3项表决议题包括保障家庭医生制度和加强保护基础医疗体系、终身禁止被定罪的恋童癖患者从事与儿童有关的工作和采购JAS 39狮鹫战斗机。除了采购JAS 39狮鹫战斗机的计划以3%的微差被否决之外，其余两项议题都获得通过。

== 9月公投 ==
在9月28日举行的公投表决了两项议题，包括选民是否支持设立统一的公共医疗保险制度和是否支持旨在「停止对服务业的增值税歧视」的公民动议。公共统一医保动议得到社会民主党、绿党、以及若干病人团体和消费者团体的赞成，动议发起人认为统一的医保制度能够节省医疗保险商的行政和宣传开支，抵销保费涨幅，在为慢性病患者和要用大笔款项治疗的病人提供医疗费这方面也会更有效率，病人在保费谈判当中也会处于更有利的地位。然而，国会内反对该动议的议员认为这是一个危险的作法，如此病人就不能自行挑选医保服务，医疗体系也会更有官僚气息；他们也反驳保费上涨是因为医学昌明和人均寿命延长，和保险商行政、宣传开支无关，废除医保竞争反而会令保费更高。而由瑞士饭店和酒店业主协会（GastroSuisse）提出的增值税调整动议则要求把餐厅应付的增值税税率由标准税率8%调低到2.5%，使之与小吃摊档应付的增值税税率一致。不过瑞士政府和联邦议会都反对这个动议，并表示这个动议会令政府的税收减少约7亿5000万法郎。
两项议题都被选民否决。

== 11月公投 ==
在11月30日举行的另一次公投合共表决三项议题，包括黄金储备动议、废除向不在瑞士工作的外籍瑞士居民征收的统一税和限制移民。全部三项议题都被选民否决。
关于黄金储备的动议要求瑞士国家银行拥有占资产总值至少两成的黄金储备，也要求瑞士当时存放在纽约联邦储备银行的黄金储备要运到瑞士储存。这项公民动议由瑞士人民党国会议员卢齐·施坦姆（Luzi Stamm）和另外两位国会议员提出，而发起公投所需的10万个签名也在2013年初收集完成。瑞士国家银行、瑞士政府和瑞士国会都反对这项动议，因为这项动议会限制瑞士国家银行的自由（包括印钞的能力），也不利瑞士国家银行为稳定物价和控制经济而行事，而且黄金在金融危机来临时未必会当作货币使用。
废除统一税动议要求住在瑞士，但不工作的外国人要按照收入和财产纳税，而不是按照生活费缴纳统一税。而由环保组织Ecopop提出的限制人口增长动议则要求把瑞士每年移民数目上限定为总人口的2%，以保护自然的生活环境。
