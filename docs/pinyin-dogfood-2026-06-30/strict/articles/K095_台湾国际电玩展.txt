台湾国际电玩展

台湾国际电玩展（英语：Taiwan Amusement Exhibition）是由上造国际公关顾问公司自行办理的电子游戏展览，主要展示大型机台的电子游戏，是台湾史上第一个电子游戏展览，最早在1993年办理，且当年在台北市与台中市办了两届。后来，在1996年的最后一次办理之下，这项展览也被浩天资讯主办的台湾电子游戏机国际产业展（英语：GTI Expo）取代，并正式走入历史。


== 展览背景 ==
台湾的电子游戏产业在1990年代属于发展阶段，游乐场与赌博电玩也盛行的同时，间接影响到社会风气，因而使部分合法经营大型机台电子游戏的厂商苦无发展之处，而为了要提升休闲电玩与益智电玩的良好形象，主办单位在1993年，决议举行此展览，当时称之「台湾国际电玩暨休闲展」，地点则选在外贸协会的松山机场展览馆。
而在历经1993年9月台中的第二届，1994年的第三届之后，各家电玩开发业者、大型机台电玩代理商看到国际电子娱乐产业的蓬勃发展，除了希望能够合法代理并中文化，让台湾消费者可以玩到符合需求的游戏，他们也呼吁政府机关应该要拿出配套的法案，让电子游戏产业合法化，并得以生存。


== 展览与活动分区 ==
国际电玩区：国际级知名厂商，包含美国娱乐器械协会的成员、日本NEC、SNK、CAPCOM、TAITO、KONAMI、SEGA等，都会展示各种不同类型的大型机台电玩，其中也有饿狼传说、弑魂武士、快打旋风|快打旋风]]、音乐机台等。
国内电玩区：除了台湾知名厂商自制的大型机台电玩以外，另外也包含了电子零组件厂商的展示，主要是提供给国际买主交换机台零件的制造商机。另外还有「产业隧道」专区，让参观者可以了解台湾游戏产业的发展史。
电玩比赛：依照每年各厂商推出的电玩状况，选择热门与新登场的大型机台电子游戏，作为比赛项目，其中，格斗类电子游戏最受到大众的热爱。
产业发展研讨会：每年邀请各厂商代表，商讨各国电玩产业的发展，与相关的法律配套因应措施。


== 历年发展 ==
1993年
主办单位征展时，开放150个摊位的承租，国际展区邀请美国、日本、澳洲、英国等国外厂商参展，另初步规划电脑娱乐软体区、大型电玩区、游乐器商品区及电玩相关零件商品区。
电玩竞赛部分，设计了「娃娃机抓娃娃大赛」、「环游世界滚珠大赛」和「数字方块」等电子竞赛活动，此外，除了大型机台，PC平台的游戏也在国内展区中展出，开幕典礼更吸引了立法委员翁大铭的参观。
由于第三波公司代理的光荣公司三国志电玩受到欢迎，加上许多仿冒的电脑游戏充斥于电脑商场，因此，有游戏业者出面呼吁大众支持著作权，并且设计时应该要以人性化、操作简易作为优先的考量。
因为第一次的办理吸引了六万人次的参观者前往会场参观，因此主办单位决议将该展览于当年9月移师台中，另行举办「台湾秋季国际电玩暨电脑娱乐展」，并正式定名英文名称为「TAE」（即「Taiwan Amusement Exhobition」）。
为了遏止非法赌博电玩与推展良好的休闲益智育乐电玩，台北市电脑商业同业公会也在9月2日─9月7日合办「第一届国际电脑娱乐展览会」，而此项展览，正是「台湾电脑多媒体展」的前身，也是「台北国际电玩展」的雏型。
台湾电玩杂志社，也是浩天资讯创办人的刘浩天表示，教育部订定的「游艺事业辅导管理规则」，不应当是行政命令，应该要提升并修正成为法定规章，才能让合法的厂商得以生存。
1994年
主办单位借由宣导「合法、健康、专业」的优良电玩，提倡「电玩分级制」，并区隔年龄层，分为限制级与普通级电玩，希望能获得大众对于合法电玩的认同。
第三届展览开幕，立法委员周荃、翁大铭、中华民国反毒促进会理事长刘昌仑成为开幕贵宾，并以「刻画未来游戏时代的电玩嘉年华盛会」，期望电玩产业能普及全民的生活。
不同于大会指定电玩的比赛，本次的电玩比赛改以厂商自办方式进行，其中，台湾厂商鈊象电子公司自行开发的「无敌双枪」与日本SEGA的「VR快打」、SNK的「龙虎拳2」，受到现场参观者的注意。
1995年
主办单位引进日本ビルドアップ公司的「拟真恐龙」（GOAS），受到年轻族群与学龄孩童参观者的好奇；另外，电玩比赛部分，鈊象电子公司自行开发的「黄飞鸿」与日本SNK的「Neo Geo」、「真武士魂」，都是受到参观者注目的焦点。
1996年
威展国际有限公司抢先于2月10日办理「台北电玩大展」，展示大型机台的休闲类游戏，与电脑周边商品，但因为性质与同年在台北世贸中心进行的「台湾电脑多媒体展」相近，因此使得2月29日举行的「第五届台湾国际电玩展」偏重展出成人电玩（柏青哥、弹珠台、餐厅宾果、雷电游戏）。
弹珠台、宾果台、麻将台受到东欧地区国家买主的重视。


== 后续 ==
在1996年4月23日，由于当时台湾的警方正在查缉游乐器电玩与周人参电玩弊案，因此引起游戏产业的不满，中华民国电玩科技协会自救委员会进而发起万人请愿自救活动，强调「电玩无罪、罪在管理」的诉求，希望政府给予大型电玩厂商发展的空间，也因为这个风波，这个电玩展览在1997年于高雄、1998年于台中办理后，就正式走入历史，取而代之的，则是浩天资讯（现：浩基有限公司）于1994年起，自行主办的台湾电子游戏机国际产业展。
