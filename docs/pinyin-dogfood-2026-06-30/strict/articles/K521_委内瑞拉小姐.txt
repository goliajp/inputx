委内瑞拉小姐

委内瑞拉小姐为委内瑞拉国内最具历史性的选美活动，自1952年开始举办至今，目前总共产生七十四届冠军。
每一年度会在首都卡拉卡斯举办委内瑞拉小姐竞选活动，每一位由国内州份（共有廿三区）代表参加，同时会颁委内瑞拉小姐冠军、委内瑞拉世界小姐、委内瑞拉国际小姐、亚军、季军及其他奖项，但委内瑞拉小姐冠军的地位比委内瑞拉世界小姐冠军及委内瑞拉国际小姐冠军还要高的。
得主冠军可代表参加环球小姐、获得委内瑞拉世界小姐则可代表参加世界小姐、获得委内瑞拉国际小姐则代表参加国际小姐、以及其他国际性选美活动如国际旅游小姐、州际小姐等可由委内瑞拉小姐世界小姐、委内瑞拉小姐国际小姐、亚军或季军等代表参加。
另外也会举办委内瑞拉地球小姐 （不是在委内瑞拉小姐竞选活动内举行），得主冠军则可代表参加地球小姐。
目前委内瑞拉小姐组织由1985年代表委国首位赢得国际小姐的妮娜·赛西丽雅担任主席。
至2025年为止，委内瑞拉为全球最强选美的国家，总共得到了七届的环球小姐冠军、六届的世界小姐冠军、九届的国际小姐冠军及两届的地球小姐冠军。


== 近代委内瑞拉小姐冠军 ==


== 代表参加环球小姐 ==
代表参加环球小姐得到冠军总共有七位，首次得到冠军是1979年，其后1981年、1986年、1996年、2008年、2009年及2013再夺得冠军。2008年 及 2009年连续两届冠军令委内瑞拉成为有始以来首个蝉联环姐后冠的国家；亚军总共有7位得到；季军则总共有5位得到；自从1976年委内瑞拉小姐得到了环球小姐亚军后，逐步成为进入决赛圈的常胜军，1983年至2003年(共21年)所有代表都进入半准决赛，其中1991年至2003年所有代表皆进入六强,成绩斐然。


== 代表参加世界小姐 ==
代表参加世界小姐得到冠军总共有六位，首次得到冠军是1955年，其后1981年、1984年、1991年、1995以及2011年再夺得冠军；亚军总共有2位得到；季军则总共有4位得到；得到第四至七名总共有8位；能进入前十五名左右总共有10位。自从1955年委内瑞拉小姐得到了世界小姐冠军后，但一直到1980年(共廿五年)似乎没有进入三甲，不过第廿六年的1981年再成功夺冠军，其后成绩愈发进步，目前于2011年夺得冠军后，尚未能有夺得冠军的成绩，1981年至2008年(共廿七年)只有9届不能进入准决赛。


== 代表参加国际小姐 ==
迄今共有九位委内瑞拉代表赢得国际小姐的后冠，首次得到冠军为1985年，其后为1997年、2000年、2003年、2006年、2010年、2015年、2018年以及2023年，是目前国际小姐中赢得次数最多的国家，表现相当优异亮眼。


== 相关纪录及轶闻 ==
※2000年委内瑞拉小姐艾娃·艾克瓦尔于2011年因罹患乳癌离世，享年28岁，其丈夫于次年以艾娃之名成立基金会。
※2004委内瑞拉小姐莫尼卡·斯皮尔·莫茨于2014年初于该国高速公路上遭遇歹徒试图抢劫袭击，中弹身亡，此事件引起国内高度关注，而后续引发民众对于该国始终居高不下的犯罪率及治安的败坏向政府进行大规模抗议。
※2008.2009年连续两年环球小姐皆由委内瑞拉夺得后冠，迄今仍为环球小姐选美史上唯一同国家蝉连两届的纪录。
※2023委内瑞拉小姐伊莉安娜．马奎斯为该选美史上第一位以母亲身分夺冠的佳丽，也是第一位于环球小姐进入前五名的母亲选手。
※2024委内瑞拉小姐史黛芬妮．安柏萨莉于媒体公开受到主席妮娜．赛西丽雅的冷落及不当对待，过去也有多位委内瑞拉小姐表示妮娜的领导风格备受争议及欠缺同理心且过于商业化，在2025的委内瑞拉小姐甚至没有出现史黛芬妮告别演说引发争议，国内亦出现要求妮娜下台的强大舆论。
※2025委内瑞拉小姐克劳拉·薇嘉丝·葛滋的母亲为1990委内瑞拉小姐的冠军安德烈娜·葛滋·布隆 ，委内瑞拉小姐史上首度出现母女先后十五年皆成为冠军。
