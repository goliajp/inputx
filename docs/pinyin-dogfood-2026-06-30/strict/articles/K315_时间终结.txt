时间终结

时间终结（英语：End Time）是亚伯拉罕诸教──犹太教、基督教和伊斯兰教中的末世论和印度教及佛教中的「末日景象」中所提及的一段时期或一个转捩点。


== 犹太教的角度 ==
于犹太教中，「时间终结」是指弥赛亚的时代。犹太教徒相信当弥赛亚来临和「将来的世代」（Olam Haba）到达时，全人类将会再次统一，和平将降临于世界，所有人将会诚心地侍奉上帝，并且上帝会重建耶路撒冷圣殿。


== 伊斯兰教的角度 ==
在伊斯兰教中，伊斯兰教徒相信于复活日（Yawm al-Qiyāmah），又称为审判日（Yawm ad-Din）中，真主安拉将会在世界终结之时举行对全人类的审判。


== 基督教的角度 ==
于天主教中，时间终结不时被描绘为一个时期的终结。而这个时期是以弥赛亚的第二次到来作为终结。天主教相信届时弥赛亚将会结束人间的所有苦难和消灭所有邪恶，净化原罪，并对全人类作出最后的审判。在此之后，人类将得到永生，并进入另一个新时期。


== 佛教的角度 ==

佛教认为宇宙的生灭反复循环，没有起始或终结。任何的终结都是起始，任何的起始都是终结。佛教认为没有一个独立的时间存在，对于生活在不同世界的众生，因业力不同，时间的长短与概念亦都各不相同。佛教亦认为，任何事物的发展都是连续的，没有一刻暂停过。所以佛教描述时间时，多以比喻或以其他事物的发展来描述时间。
佛教以“劫”（梵语：Kalpa），来描述一段长远的时间。有学者认为“劫”没有实质的精确时间，但凡佛经中出现的时间多为约数，“劫”亦被认为是一个大概的时间单位。

自寿自十岁，百年增一至八万四千岁为止，然后再百年减一至十岁为止，如是一增一减，为一小劫，二十小劫为一中劫，经成、住、坏、空，四中劫为一大劫，即一世界成毁的时间。
即1小劫可换算为1679万8000年；20小劫为1中劫，即3亿3596万年；4中劫为1大劫，即13亿4384万年。
也有以佛与辟支佛出世与否来计算的，分为「大劫」（mahākalpa）和「中劫」（antarakalpa）两种，「小劫」同「中劫」。这种算法的「劫」没有固定长度，但80小劫即等于1大劫，若按以上算法推度，此一大劫为268亿7680万年。


== 其他宗教的角度 ==
很多不同的宗教也有自己的末世论，多与转世或赎罪有关。


== 现代科学的角度 ==
自从18世纪起，人类对科学方面的认识加深，人类明白地球的年龄远比以往人类认为只有几千年大得多。因此，末世被科学家认定为「宇宙的终极命运」，即世界末日将可能是宇宙热寂，宇宙中再也没有任何可以维持运动或是生命的能量存在的时候。那样，末世将不是好几千年以内的事，而是10100年后的事了。
