慕舆文

慕舆文（？—？），五胡十六国的前燕人与后燕时期人。


== 家庭背景 ==
父亲慕舆句为五胡十六国前燕太子的太保，此官职负责辅佐并监护年幼时期的太子，可谓十分接近权力核心。鉴于《永乐大典》中述及的慕舆句「勤恪廉靖、心计默识、不案薄书、终始无漏」，公元302年(晋太安元年)，与前燕的开国君主慕容廆执掌政府财库，主要负责财务支出。公元350年(东晋永和元年)，后赵发生动乱，慕容句前去追击，对阵幽州刺史王永与后赵大将邓恒。


== 生平概述 ==


==== 出生与成长时期简介 ====
慕舆文是慕舆句之子，曾经担任平阳太守一职。


==== 淝水之后的乱世与慕舆文的一展长才 ====
西元383年11月(东晋太元八年/前秦建元十九年)，淝水之战爆发，前秦皇帝苻坚领八十余万的兵力南下入侵东晋。此时东晋的当朝宰相为谢安，以七万兵力对阵近十二倍差距的前秦军队。纵使前秦地大物博，但在谢安谢玄二人带领的东晋可说是实力雄厚。利用北府兵与土断制度将人力资源做最大限度的运用，最后以寡击众东晋击败了一代强权前秦。
北府兵所训练出来的劲旅与同期的军队并非同一个等级的，此举大大的强化了东晋的军备实力；土断制增进了东晋朝廷内部的税收，史家也曾评断这段时期也为东晋财务较为充裕的一段时间。此举也被南朝宋的开国君王刘裕大力称赞。
然而这便是延续中国分裂的主因。
自淝水之战的结束以前秦大败作为收场，其中前秦征南大将军符融战死沙场，385年(东晋太元十年/前秦建元二十一年)符坚遭羌族的姚景茂(姚苌)所杀，这位姚景茂正是后秦的开国君主；南方的东晋朝廷也鸡犬不宁，鉴于宰相谢安与将军谢玄双双退隐，迫使东晋只能趋于守势。东晋先是延续了十余年，最后在西元420年遭到南朝宋刘裕的篡位；反之北方则是要等到西元439年北魏的出现统一北方。
此时的前燕也是腥风血雨，第五任前燕君主慕容𬀩原先遭前秦大败，作为前秦的败将后任新兴侯(类似尚书一职)。然而公元前283年前秦的大败，此时正是慕容𬀩起兵的大好时机，加上慕容垂先是举兵建立「后燕」，紧接著慕容泓建立「西燕」，并两国皆与前秦的军队陷于战事。上述三事更激起了慕容𬀩的复国情操，为此，他先是与慕容肃联合在长安城内的鲜卑人制造混乱，并藉著儿子婚礼为由设计杀害苻坚。然而符坚有事不克出席，事迹败露，两人遭到符坚的杀害，并连带处分城内的鲜卑人。
然而这正是使得慕舆文出人头地的重要机运。淝水大战后，北方部族全陷入了混乱，伴随著是五胡十六国的出现。为了制止此局面的扩大，符坚派出大将刘库仁迎击后燕。后燕发起了十分顽强的抵抗，围困了符坚之子符丕与幽州刺史王永，刘库仁率军前往救援，遭到平阳太守慕舆文的伏击，仓皇逃往马厩中，被慕舆文发现，当场斩首之。
刘库仁死后，尤其弟刘眷继承其兄摄国事的职位，刘卫辰与燕成武帝慕容垂交好，赠其良马希望维持友谊。然而赠送的过程中，刘眷领军大败慕容军，此举引发慕容垂十分不满，派出慕舆文前往制裁。追击后与刘眷占得难分难舍，刘库仁之子刘显见其叔陷入危难，立刻上前救其，然而慕舆文的战斗能力强大，大败叔侄俩，使他们败逃回平阳一带。
刘显在逃回北方之后，杀害叔父刘眷，并自立为王。


== 趣闻轶事 ==
慕舆文的姓氏为慕舆，而慕舆二字为复姓，且与慕容二字的读音类似，为了避讳，天赐末年，全面以「舆」为氏，不敢再用慕舆二字。然而在北魏宣武帝时期(延昌末年/西元515年)才得以恢复旧姓氏。

「晋惠帝永宁元年。鲜卑宇文部围棘城慕容廆击破之。廆以其臣慕舆句。勤恪廉靖。使掌府库。句心计黙识。不案簿书。终始无漏。以慕舆句明〉敏精审。使兴狱讼。覆讯清允。　集覧。慕舆代北复姓。或云。即慕容氏后讹转为慕舆耳。恐非。隋书食货志魏文宣受禅。多所创革。六坊之内徙者。更〉加简练。每一人必当百人。任其临阵必死。然后取之。谓之百保。鲜卑又简华人之勇力绝伦者。」
