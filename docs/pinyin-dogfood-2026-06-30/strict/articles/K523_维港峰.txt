维港峰

维港峰（英语：Upton），是位于香港香港岛西营盘干诺道西的单幢住宅，楼高共41层，由英皇集团发展及管理，承建商为佳盛建筑，于2015年第3季入伙。
维港峰合共提供125个住宅单位，实用面积介乎524至3,518平方呎。


== 住宅 ==
维港峰共高41层（不设4楼、13楼、14楼、24楼、34楼及44楼），其中基座占4层。维港峰的6楼至顶层46楼为住宅楼层(23楼为庇护层)，每层各设2至5伙单位 (6至22楼各设5伙；25至43楼各设3伙；45及46楼各设2伙)，合共提供125个分层住宅。
维港峰单位的实用面积介乎524至3,518平方呎，间隔涵盖一至六房。户户采用独立式厨房设计，各配罝16至46平方呎露台。而除了两户顶层复式户以外，所有单位另设有8至62平方呎窗台。
景观方面，项目单位北向电车厂及西区副食品挑发市场，建筑物属有限高度，因此低层住户亦可享有海景，高层单位更可远眺昂船洲大桥、青马大桥及汲水门大桥等景致，视野可谓十分开扬。


=== 标准户 ===
标准户共有112伙，实用面积由539至1,753平方呎，间隔分为1房2厅（连套房）及储物室连厕、2房2厅（连套房）、2房2厅（连套房）及储物室、3房2厅（连套房）及储物室连厕、4房2厅（连双套房）及储物室连厕等多种，均配罝14至16平方呎工作平台。


=== 特色户 ===
特色户共有13伙，可分为连平台户及复式户两种：

连平台户仅设5伙，只设于6楼，实用面积由524至1, 166平方呎，间隔分为1房2厅（连套房）及储物室连厕、2房2厅（连套房）及储物室、3房2厅（连套房）及储物室连厕三种，各配置11至353平方呎平台。
复式户则有8伙，分布于38至46楼A及B室，实用面积由2,014至3,518平方呎，间隔分为2房2厅（连套房）及储物室连厕、3房2厅（连3套房）及储物室连厕、5房2厅（连3套房）及储物室连厕、6房2厅（连3套房）及储物室连厕四种。部份复式户设有14或16平方呎工作平台。当中45及46楼两伙顶层复式户配置有896或1,525平方呎平台、773或1,219平方呎天台及一个101平方呎梯屋。


== 屋苑设施 ==
维港峰设有面积达16,978平方呎的住客会所，提供包括25米室内外连恒温游泳池、儿童嬉水池、按摩池、健身室、室外烧烤区、儿童游乐场及桑拿室等设施，供住户享用。


== 历史 ==
维港峰 前身为一幢由长江实业地产在1972年兴建位于干诺道西178-180号及德辅道西343-345号楼高21层共约有44伙的工业大厦 ——长嘉工业大厦，及后陆续出售单位，早于2008年2月其中占该厦91%业权的44名业主，委托第一太平戴维斯以意向价约13.7亿元透过联合方式招标出售，唯未有成功出售；至2009年4月英皇集团（国际）委托田生集团计划以约10亿元收购全幢全部业权，其中该厦10楼两个单位由英皇集团持有，而亦有部分地铺由创兴银行廖氏家族成员持有，及后小业主向财团提出加价5%要求，终以10.5亿元取得逾92%业权，至2010年1月田生集团（宏辉集团前身）把业权转交英皇集团（国际），发展商于4月因未能购入3个工业单位而申请强制拍卖，最终发展商并没有进行强制拍卖，于2011年3月以13.6亿元完成统一所有业权。
地盘面积约18267方呎，2009年9月地盘获屋宇署批准兴建1幢包括4层停车场的30层高商厦，总楼面约273,989方呎，至2010年发展商亦获批以地积比率10.1倍重建一幢提供少于200伙住宅，并附设地下商舖及60个车位的约45至46层高商住项目；最终项目建成后者，总楼面约18.8万方呎。
2025年6月，英皇国际以9,288万港元出售维港峰基座商舖地下1至3号舖，建筑面积约8,182平方呎，呎价11,352元。买家是李暖升（基金）有限公司。


== 教育 ==
维港峰小学校网为11。中学校网为中西区，皆为传统名校网。区内名校及国际级著名学府林立，而屋苑距离香港最高学府的香港大学亦只是10分钟步距，弥漫浓厚学术文化气息，故一直备受望子成龙的家长欢迎。
中西区11校网一共有16所小学，是传统名校网之一。区内小学包括嘉诺撒圣心学校、圣士提反女子中学附属小学、般咸道官立小学、中西区圣安多尼学校及圣公会圣彼得小学等；中学则有圣保罗男女中学、圣保罗书院、圣士提反女子中学、英皇书院、英华女学校、圣若瑟书院及高主教书院等。
而国际学府包括: 己连拿小学 (ESF)、坚尼地小学 (ESF)、山顶小学 (ESF)、香港犹太教国际学校、德瑞国际学校及港湾学校等。


== 宣传 ==
英皇集团(国际)执行董事张炳强表示预计花逾1亿元作宣传 维港峰 的开支，其中同集团艺人谢霆锋为代言人，以宣传物业，而首3名内地买家可获谢霆锋颁发奖品。
另譤请了香港作家及传媒工作者陶杰为楼盘命名，其中英文名「Upton」他表示「呢个up，唔系斋噏个噏，系up and coming 个up，系up climbing个up，向上游，游去边呢？就游去上流。呢个upton，声又响，好配合，是买家上楼的身份。」而英皇集团员工则享有购买优惠。


== 途经之公共交通服务 ==
交通方面，楼盘距离港铁香港大学站约5分钟步程。同时附近有多条巴士、小巴路线及电车，可乘搭前往港九新界多区。
