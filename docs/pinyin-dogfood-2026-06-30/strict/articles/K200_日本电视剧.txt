日本电视剧

日本剧集（日语：日本ドラマ），简称日剧（ドラマ），是指日本制作及播出的剧集，包括电视剧（テレビドラマ）、网络剧（webドラマ），也可以包括其他形式发行的剧集，比如录像带、DVD首次发行的剧集等。
日剧故事题材内容多样，不少著重于描述特定职业的职场生态，或以一般大众日常生活场景为主轴，或以漫画改编故事，甚至大胆揭露社会黑暗面。


== 概要 ==
第一部日剧为NHK电视台1940年试验播放的《晚饭前》。这次试验播放取得了很好的回响。NHK已经计划好制作第二套电视剧进行试验播放。但是不久后，太平洋战争爆发，计划被迫搁置。直到战后的1950年代，日本才正式开始播放电视剧，亦随着黑白电视机的普及而兴起。直到1969年1月，大河剧《天与地》才为彩色播出的节目。
由于日本制作电视剧是边拍边播，每天同一时段有不同的电视剧播出，而且每周播出一集，以一季（三个月）为一个周期，故大部分的日剧的集数比较少，在11或12集左右，此习惯从1980年代开始。不过还是有一些集数比较长的日剧，如NHK的大河剧与晨间剧，预算成本比较高，制作上也较为细致与严谨。还有较特殊的剧种为特摄，其性质介于电视剧与动画之间。
自从1991年《东京爱情故事》、1993年《一个屋簷下》、1996年《悠长假期》、1997年《恋爱世纪》等剧陆续在日本以及香港、台湾等邻近地区播出后，不但在日本国内引发回响，在其他得以收看日剧的地区也开始产生显著的影响力。随著日本流行文化的逐渐盛行，之后数年播出的一些著名剧集，亦曾在各地获得相当高的收视率，并成为哈日族的主要话题，与日语学习者的主要参考对象，许多情节也被其他电影或电视剧仿傚。
不过2001年之后，由于韩国电视剧随著韩国流行文化向海外扩张而兴起，剧集采购成本亦较为便宜，因此许多中国大陆、香港和台湾的电视台转而采购韩剧，并在黄金时段播出，使得原本长期居于收视较前地位的日剧备受威胁。尽管如此，偶然也会有个别日剧受到相当程度的注目，如2003年的《白色巨塔》、2009年的《仁医》、2013年的《半泽直树》和《小海女》等。
在台湾，定期播出日剧的电视台有纬来日本台、国兴卫视与Z频道；在香港，各电视台旗下各频道都会不定期播放日剧，包括无线电视、有线电视和Now宽频电视；在马来西亚，播出日剧的电视台主要为 8TV 八度空间、Astro；而在中国大陆，由于政策原因，日剧同美剧等境外影视作品一样已很少在官办的电视台上播出，更多的是在网络上以正版或盗版的方式流传。
日剧的海外销售呈下跌趋势。2021年度日剧出口总额为36.1亿日圆，仅占所有日本电视节目出口总额的5.5%。主因包括制作预算不及竞争者美剧、韩剧，以及集数过少。


== 制作体系 ==
日本电视剧与韩国电视剧、台湾电视剧的制作体系相同，也是边拍边播，但在正式公开播出前会先拍好2、3集存档，故在剧情上也较为稳定，同时也甚少因为观众的意见而随意更动剧本，与演员经常因为赶拍戏剧而常发生意外事故或有健康风险的台、韩相比，日本演员这方面的风险就少了很多，但也因为这种制作模式，日本电视剧的收视率波动率也较台、韩电视剧要来的大。
不过制作单位都会保有「最终决定权」来进行剧情修改的权限。

== 特殊现象 ==
集数短
与东亚其他地方 ( 如香港、台湾、中国大陆和韩国 ) 相比，日本电视剧除了NHK的晨间连续剧与大河剧、东海电视台（富士系）的午间剧及朝日电视的电视剧《相棒》外，1980年以后的日本电视剧几乎清一色集数都不长，大部分日本电视剧集数都只有9～12集左右，偶尔甚至会出现只有5～8集或少数14～20集就完结的情况。
另外特殊的电视剧特别篇，长度跟电视电影的长度差不多，一般仅有一集，有些跟比连续剧推出还来早的特别篇也有关，例如《时尚女王》、《杀人草莓夜》、《ST 警视厅科学特搜班》、《最后的晚餐〜刑事・远野一行与七个嫌疑人〜》，依应节日的特别篇，例如《NHK正月时代剧》、《东京电视台新春大型时代剧》。有些原先为集数多的连续剧，现在以几乎每年播出特别篇的方式推出新作品，例如《世界奇妙物语》、《毛骨悚然撞鬼经验》、《冷暖人间》、《必杀仕事人》。有些有两集以上的，例如《我家的历史》、《东方快车谋杀案》、《永远的0》。
主演和助演
目前的日本电视剧通常只有一个演员出任主演，最多有两个，也可以称为第一主演，其余的均一律为助演，包括被外国人视为的第二主演。有两个演员出任第一主演，则称为「W主演」（W的发音接近Double，日文假名发音一样），基本上两个第一主演的日本电视剧只是占少数。
也正因为「只有一个主演」这种大多数情况，在日本很多时候最佳男女助演奖项的评选竞争也会比最佳男女主演来得激烈，其奖项价值也不比最佳男女主演低。
社会风气
一些起源于日本的社会风气经常被拍摄成为电视剧，包括辣妹、御宅族、草食男、肉食女、怪兽家长等等。
拍摄地
除了晨间连续剧和大河剧以外，日本电视剧的主要拍摄地场景还是在东京或横滨等首都圈地区；其次才是日本的其他各县市，有些日剧偶尔也有前往国外拍摄的桥段。
杰尼斯偶像肖像权
一般电视剧通常在官方网站或是文宣上都会将演员的头像放在所饰演的角色介绍旁边，但日本的杰尼斯事务所对旗下艺人的肖像权向来把关较为严格，因而过去日本电视剧只要介绍演员角色时，只要是杰尼斯旗下艺人的头像通常是不放出来的或是直接拿原作图像来代替的现象。但近年杰尼斯对肖像应用于电视剧角色介绍已有所放宽，杰尼斯旗下艺人的头像可以用于角色介绍。以空中急诊英雄系列为例，于2008及2010年播放之第一及第二季，官方网站人物关系图以剪影代替饰演主角蓝泽耕作之山下智久头像；但于2017年播放之第三季中，官网已可使用山下智久之头像于人物关系图。
不随意更改剧本或增加集数
与常因观众意见而随意更改剧本或增加集数的台韩电视剧相较，日本电视剧很少做这样的变动，除了不得已才做修改（例如遇到电视尺度、遭投诉有严重问题，可能在后面集数稍作剪辑），但如果收视不振，仍会将电视剧腰斩。
外国影星的演出
有部分的日剧会有外国影星的加入演出，包括翁倩玉、林志玲、陈慧琳、王菲、柳时元、崔智友、徐若瑄、元斌、金泰希等等。
与电影近期推出
有部分的日剧与电影近期推出，甚至会跟近期上映的电影有关，包括《诈欺游戏》番外篇、《MW 第0章 〜恶魔的游戏〜》、《鬼压床了没 特别版 〜完美的门房》、《黑百合住宅区～序章～》、《大奥 ～诞生【有功·家光篇】》、《近距离恋爱～Season Zero～》、《进击的巨人》、《信长协奏曲》。
原创性
近年原创作品较少，改编自小说或漫画之作品较多；改编书籍之电视剧与被改编的原作之初版日期时间缩短。

晚上时段，20:00~23:00的时段，因为比其他时段观看的人数来的多，故又称作黄金时段，每集约50分钟，大多为13集内。但NHK大河剧以一剧唯一整年拨出，每集约50分钟，为50集左右。
深夜时段，通常24:00（即隔天0:00）之后的剧集都归类于此，每集约30分钟、15分钟，甚至有5分钟，同样地，大多为13集内。这段时间的节目在日本国外播出的分级相对就比较不适合阖家观赏。
同一时段的电视剧各电视台不一定会在同一时间点播出，例如：朝日电视台周四晚间八点推理连续剧（木8，20:00）、朝日电视台周四晚间九点连续剧（木9，21:00）、富士电视台周四连续剧（木10，22:00）、周四时代剧（木10，22:00），相对不会抢收视率。
与其他东亚国家剧集不同的是，收视率的不同时段皆有一定的门槛，也视依前几档剧集收视率的幅降多寡，午间剧时段4%以上，晚上时段10%以上，深夜剧2%以上，可以决定由收视率来是否废除此时段，例如：读卖电视台周四连续剧收视不济而废除，另外，四大电视网（或电视台）不常安排同一时段、同一时间作收视竞争，因此收视率若不是因大众的喜好，大部分不受他台影响，但是可能会受到他台的非戏剧节目（例如：棒球比赛）影响。
