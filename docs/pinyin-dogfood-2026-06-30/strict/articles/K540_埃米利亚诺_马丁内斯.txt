埃米利亚诺·马丁内斯

达米安·埃米利亚诺·马丁内斯（西班牙语：Damián Emiliano Martínez，1992年9月2日—），绰号迪布（Dibu），是一名阿根廷足球运动员，场上位置是守门员，目前效力于英超球队阿士东维拉并担任副队长。代表阿根廷国家足球队参加国际比赛。2022年帮助阿根廷夺得世界杯，并获得当届金手套奖。身材高大，弹跳优秀，防御覆盖面广。 反应速度快，球路预判能力极强，选位亦十分优秀，是现役最佳门将之一。


== 早年 ==
马天尼斯1992年9月2日于阿根廷马德普拉塔出生，是家中次子。父亲是当地的足球员。他家境贫困，甚至曾三餐不继。


== 球会生涯 ==


=== 独立队 ===
马天尼斯于阿根廷马德普拉塔出生，于独立队开始其职业生涯。16岁时，被邀请加入阿仙奴U17青年军。


=== 阿森纳 ===


==== 早期外借 ====
由于英格兰乙组足球联赛球会牛津联阵中门将瑞恩·克拉克、韦恩·布朗受伤，加上康纳·里普利完结外借期，马天尼斯被外借至牛津联。2012年5月5日，他于联赛煞科战对阵韦尔港上阵，最终球队以3比0胜出。


==== 联赛杯上阵 ====
2012年8月26日和9月2日，马天尼斯在对阵史笃城和利物浦的联赛比赛中出任后备门将，因什琴斯尼和乌卡什·法比安斯基双双受伤。9月26日，马天尼斯在英格兰联赛杯第3圈对阵高云地利时，首次代表阿仙奴上阵。他于联赛杯第4圈对阵雷丁的比赛中，第2次为阿仙奴上阵，该场比赛球队曾以0比4落后，其后反胜7比5晋级第5圈。


==== 谢周三（外借） ====
2013年10月15日，马天尼斯被紧急外借至英格兰足球冠军联赛球会谢周三，为期28日。11月14日，阿仙奴宣布延长外借期至2014年1月1日。11月23日，他在对阵哈德斯菲尔德时首次代表球队上阵。其后，球会宣布外借期将延长至赛季完结。


==== 出任球队后备门将 ====
2014年8月10日，马天尼斯在2014年英格兰社区盾的比赛中担任后备，未有被派遣上阵，球队最终以3比0胜出赢得英格兰社区盾。马天尼斯在欧洲联赛冠军杯对阵安德莱赫特的比赛中首次代表阿仙奴上阵，最终球队以2比1胜出。于对阵曼联的比赛中，他于下半场后备入替受伤的沃伊切赫·什琴斯尼，首次在英超上阵。
因为沃伊切赫·什琴斯尼和戴维·奥斯皮纳2名门将皆受伤，马天尼斯在对阵多特蒙德的比赛中正选上阵，协助球队保持不失球，以2比0胜出。他于比赛中的「零失误」表现令他入选欧洲联赛冠军杯的本轮最佳阵容。11月29日，他在对阵西布朗时首次于联赛正选上阵，4日后于对阵修咸顿的比赛中再次正选上阵，两场比赛皆以1比0胜出。


==== 罗瑟勒姆（外借） ====
2015年3月20日，马天尼斯被紧急外借至英格兰足球冠军联赛球会罗瑟勒姆，直至赛季完结。次日，他在对阵谢周三的比赛中首次为球队上阵，但球队在补时阶段被对手连进两球，于主场以2比3落败。


==== 续任球队后备门将 ====
2015年8月2日，马天尼斯在2015年英格兰社区盾的比赛中担任切赫的后备，于比赛并没有被派遣上场，最终阿仙奴小胜车路士1比0夺标。在8月11日，马天尼斯被外借至英格兰足球冠军联赛球会狼队，为期1个赛季。
2017年4月5日，马天尼斯在主胜韦斯咸3比0的联赛时，首次于2016-17赛季联赛上阵。


==== 基达菲（外借） ====
2017年8月2日，马天尼斯被外借至西班牙甲组足球联赛球会基达菲，为期1年。


==== 雷丁（外借） ====
2019年1月23日，马天尼斯被外借至英格兰冠军足球联赛球会雷丁，直至赛季结束。1月29日，他于对阵保顿时首次上阵，并于数日后对阵阿士东维拉时获得全场最佳球员。


==== 阿仙奴正选门将 ====
2020年6月20日，莱诺在对阵白礼顿的比赛中受伤，马天尼斯后备入替，自2016-17赛季后首次于英超上阵。直至赛季完结，他一直担任球队的正选门将，其出色的表现亦被称赞，其中前球队射手伊恩·赖特表示他效力阿仙奴期间的表现具统治力和出色。8月1日，马天尼斯以正选上阵2020年英格兰足总杯决赛，助球队赢得第14次冠军，赛后他于捧杯后激动落泪。


=== 阿斯顿维拉 ===
2020年9月16日，阿斯顿维拉以2000万英镑从阿森纳签下达米安·马丁内斯，并提供为期四年的合约。
后来合约再续期至2027年。
2020年9月21日，马丁内斯在球队对上雪菲尔联的主场比赛中首次亮相。
2023年4月1日，阿斯顿维拉在联赛中客场2-0击败切尔西，马丁内斯打破球队队史零封纪录，在100场比赛中34次零封对手。
当赛季，马丁内斯帮助阿斯顿维拉以英超第七名的成绩时隔13年再次进军欧战赛事。
2026年5月11日，他在对阵伯恩利的2比2平局中送出了职业生涯首次助攻。2026年5月20日，马丁内斯在2026年欧霸杯决赛中首发上阵，阿斯顿维拉在该场比赛中以3比0击败弗莱堡。


== 国家队生涯 ==
2011年6月，马天尼斯首次获阿根廷国家足球队征召，代替奥斯卡·乌斯塔里列入对阵尼日利亚国家足球队的比赛。
2020年10月，马丁内斯再次获得阿根廷国家足球队征召。
2021年6月3日，马丁内斯在2022年世界杯南美洲区外围赛对阵智利的比赛完成国家队首秀。
2021年6月，马丁内斯入选了阿根廷参加2021年美洲国家杯的大名单。 7月10日，他帮助了阿根廷队获得美洲杯冠军，并当选美洲杯最佳门将。
2022年11月，马丁内斯获得阿根廷国家足球队征召出战2022年世界杯，并穿上23号球衣。在阿根廷与荷兰对决的12码对决时接连挡下2球，帮助阿根廷晋级四强，四强赛中也成功零封克罗地亚并晋级决赛。而他也在对阵法国的决赛奉献多次扑救，关键在加时赛123分钟中，扑出一个单刀球，并于点球大战中再度扑出一球，这是马丁内斯的封神之战。成功帮助阿根廷自1986年后再度捧起大力神杯。凭借在一届世界杯中主导两次点球大战的优异表现，他也获得世界杯金手套奖。
