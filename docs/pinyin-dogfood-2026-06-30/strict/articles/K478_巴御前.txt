巴御前

巴御前（日语：巴御前／ともえごぜん，罗马化：Tomoe Gozen，字鞆绘；生卒年不详，约为12世纪前后）是平安时代末期的著名女武者。据《平家物语》记载，她是侍奉源义仲的女武者；据《源平闘诤录》记载，她是樋口兼光的女儿；据《源平盛衰记》记载，她是中原兼远的女儿、樋口兼光、今井兼平的姊妹、源义仲的妾。义仲败亡后即下落不明，其后事迹众说纷纭；后经过不断演化，成为日本文学作品中所塑造的英雄人物之一。


== 人物像 ==
军记物语『平家物语』的『觉一本』只出现在「木曾最期」一章中，木曾四天王与源义仲一起参与讨伐平氏的行动，在源平合战中被描绘成一位拥有强大力量和强弓的女武者。
「木曾殿从信浓带来了两个侍女，一个叫巴，另一个叫山吹。山吹（因病）被好好照顾著留在都城里。其中巴更是肤色白皙、头发长、相貌出众。更是强弓精兵、一人当千。」在宇治川之战的记载中，义仲失败后，最后只剩下他自己、今井兼平、巴御前、手冢光盛和手冢别当5人，但巴御前竟然没有被打倒。义仲对巴说：「妳是女性，所以妳想逃到哪里就逃到哪里。我已下定决心要战斗到底，如果最后连女性都带在身边，那就不太好。」巴虽然不愿意离开，但被义仲再三劝说，最后才说：「让我最后再尽一份力吧。」在这时，有名的敌将御田（恩田）八郎师重出现，巴便骑著马冲向他，砍下他的首级。之后巴脱下铠甲，逃往东国，从此在故事中消失踪影。
在八坂流的『百二十句本』中，巴在击退追兵后，被义仲劝说要退走，她认为最后的奉公就是为后世祈福，于是朝东方而去，下落不明。而在『长门本』中则说，巴在逃亡后，定居于越后国的友杉，并成为尼姑。
被认为保留最原初形式的『延庆本』记载，巴从小就与义仲一同成长，擅长武术格斗，是义仲锻炼的练习对象。长大后她也被召唤参加战斗。当义仲势力仅剩7人时，巴就从左右两侧包夹攻击敌军，结果更成功斩首两名武将。到粟津之战时，义仲势力只剩下5人，但巴已下落不明，不知是死在战场上还是逃脱。
在『源平盛衰记』中，巴也被记载为俱利伽罗峠之战的大将之一。在横田河原之战中，她更是讨伐了7名武士，建立很高的声名(『长门本』也有类似的描述)。在宇治川之战中，描述巴与畠山重忠的战斗。当重忠问及半泽六郎巴是谁时，他答道：「她是木曾殿的奶娘，名叫巴，是中三权头的女儿。她擅长射箭，骑马也很熟练。虽然是奶娘，但却是主公的爱妾，在家中照顾少年，到了战场上却是一方大将军，威名不逊于今井、樋口兄弟，是一位令人敬畏的人物。」在这里，描述巴与敌将的对决，以及她最后与义仲的告别更加详细。提到「木曾殿有两位女将军，一位是葵，她在去年春天的砺并山合战中阵亡」，在击败内田三郎家吉后，义仲告诉巴：「我去年春天离开信浓时抛下妻子，至今再也没能见面，真是万分悲伤。所以我想，在最后这一役中为世人知晓这个消息，或许也算是我的最后一份奉公吧。请妳赶紧偷偷逃去信浓，将这件事告诉大家」说完，她便离开战场。据说，在逃亡后，巴被源頼朝召到镰仓，成为和田义盛的妻子，生下朝比奈义秀。之后在和田合战后，她到越中国砺波郡福光的石黑氏隐居，出家修行，精勤追悼亡夫、父母以及儿子的菩提，最终以91岁高龄圆寂。
虽然『觉一本』中没有记载她的年龄，但『百二十句本』中是22、23岁，『延庆本』中是30岁左右，『长门本』中是32岁，『源平盛衰记』中是32岁。


== 史实以外 ==
巴御前这个角色只出现在军记物语『平家物语』和『源平盛衰记』中，在当时的一手史料以及镰仓幕府所编纂的『吾妻镜』中，都没有确认到她的存在。她作为一位女武将的描述也令人存疑，很可能是文学创作的虚构成分。在『平家物语』中，对巴御前的描述非常简略，也未提及与义仲的关系，但在后来编撰的『源平盛衰记』中，她的人物形象则被大幅增添和刻画。
不过，在『吾妻镜』中有记载，越后城氏的一族板额御前，在作为讨伐军一员时表现出色，给予敌军重大损害。这显示，当时信浓和甲信越地区的武士家庭，女性也接受了一线级的战斗训练,能够参与实际作战。在镰仓时代，男女平等的财产分配制度也使得女性参与战斗的情况得到承认。
此外，在神话故事中，也有很多女性参与战斗的例子，如神功皇后、崇神天皇时代统治期间叛乱的武埴安彦命及其妻吾田媛，以及随日本武尊东征的弟橘媛等，以当时的女性参加战斗并不罕见。对于巴御前的情况，《源平盛衰记》也描述她「额上戴天冠」，暗示她具有一定的宗教性特质。该书又称巴与义仲的乳母子，这与柳田国男提出的「妹之力」概念也有相关联。


== 异说 ==
作家海音寺潮五郎推测，由于金刺氏的据点山吹城的存在，巴和山吹可能是义仲支持势力中原氏和金刺氏家族中，派遣出来担任副官或秘书官的优秀女性。
明治时代的自由民权运动家武居用拙在他的著作『岐苏古今沿革志』中记载如下：从小接受皇别的中原兼远精心教育的人物有木曾义仲、巴御前、今井兼平、樋口兼光。义仲起兵后，能战斗的女性只有巴一人。作为义仲的贴身侍从与他共同生存、共同战斗，是巴的愿望所在。在军记物语『源平盛衰记』中，巴被描述为兼远的女儿，成为义仲的妾侍。但现实来看，皇别的兼远决不可能将自己的女儿降为妾侍(游女或便女)。义仲的贴身侧室应该就是巴。而且巴早在义仲起兵前就已经生下义高，说明她原本是义仲的正室。到义仲起兵时，能够作战的只有巴，她不得不成为义仲的贴身侍从，与他共同奋战。巴御前的形象只出现在『平家物语』和『源平盛衰记』这些军记物语中，在当时的一手史料或镰仓幕府编纂的『吾妻镜』中都找不到她的记录。『源平盛衰记』很可能包含大量文学虚构成分。作为败者，他们将妾侍和正妻搞混淆，这无疑是一种侮辱和凌虐；正确的情况应该是，他们将(地方豪族的女儿或败者的女儿)纳为妾侍，而(同盟国的女儿或皇族的女儿)则作为正室。


== 墓所 ==

目前在各地仍保留有被认定为巴御前墓碑的墓地。主要地点如下所示。

义仲寺（滋贺县大津市） - 根据寺庙的传说，巴御前在近江粟津的村落中，为了祭拜战死的义仲而修建茅蓬庵居。。别名『巴寺』。寺庙内有一座被称为巴冢的墓地，据信就是巴御前的墓。
徳音寺（长野县木曾郡木曾町） - 木曾一族的菩提寺。寺庙内有义仲、义仲之母・小枝御前、巴御前、樋口兼光、今井兼平等人的墓。
巴冢公园（富山县南砺市） - 南砺市的福光地区，据『源平盛衰记』等记载是巴御前长眠的地方。公园内有一座据说埋葬她遗体的冢。旁边种有一棵高12公尺、树干周围3公尺的松树，是该市指定的天然纪念物。每年10月22日，也就是传说中巴御前忌日当天，都会在此举办「巴忌」的追悼活动。。
倶利伽罗县定公园（富山县小矢部市） - 倶利伽罗峠之战的古战场。公园内有巴冢和葵冢两座墓碑。葵御前是与巴御前一同效忠于义仲，并在倶利伽罗峠之战中牺牲的人物。传说巴御前临终时曾说：「我死后，请将我葬在砺波山上的葵冢旁边」。。这片区域被指定为「葵冢・巴冢古坟群」，列为埋藏文化资产。
出丸稻荷神社（新潟县上越市） - 当义仲在近江之战中阵亡时，巴出家为尼姑并搬到高田。传说她在出丸隐居并结束自己的生命以安慰义仲的灵魂。。寺庙内的宝箧印式塔据说是巴御前的墓。
善荣寺（神奈川县小田原市） - 据说，巴御前为了祈求木曾义仲和和田义盛的菩提而建造这座神社。寺庙内有木曾义仲和巴御前的五轮塔。
此外，神奈川县横须贺市还有五轮塔（同市岩户）和冢（同市森崎），据说是巴御前的坟墓。。
