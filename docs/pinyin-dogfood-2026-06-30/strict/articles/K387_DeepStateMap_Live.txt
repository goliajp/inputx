DeepStateMap.Live

DeepStateMap.Live是一个公开来源情报互动式线上地图。该地图显示自2022年俄罗斯全面入侵乌克兰期间，俄罗斯和乌克兰军队的军事行动。该地图由非营利、非政府组织「Deep State UA」于2022年2月24日（即入侵当天）建立。它定期更新，以反映前线变化、俄军军事编队的动向以及战争中的其他重大事件，如莫斯科号巡洋舰沉没事件。
在俄罗斯入侵乌克兰之前，Deep State UA最初专注于即时通讯软体Telegram上发布与全球新闻和政治相关的内容，并在此期间创建了第一个2021年塔利班攻势期间全球冲突的线上地图。Deep State UA团队在与Google发生争执后，不再使用通用的Google地图背景，设计了自己的地图背景和互动功能，从而将自己与类似的线上地图区分开来。目前该地图的来源混合了视觉资讯（照片或影片）和已确认的可靠来源。
Deep State UA团队制作的地图和其他军事分析已被英国广播公司和乌克兰真理报等新闻媒体引用。截至2024年2月，该地图的浏览量已超过10亿次，成为乌克兰最受欢迎的俄乌战争线上地图，也是全球最流行的线上军事地图之一。


== 历史 ==


=== Deep State UA ===
Deep State UA是由罗曼·波霍里雷（Roman Pohorily）和鲁斯兰·米库拉（Ruslan Mykula）于2020年2月创建的非政府组织。初时，该组织专注于在即时通讯软件Telegram发布关于全球地缘政治、军事的相关内容，包括2019冠状病毒病疫情、叙利亚内战、佐治·弗洛伊德抗议、第二次纳卡战争和2021年塔利班攻势等事件。正是在2021年塔利班攻势期间，该组织首次尝试制作带有动态战线的线上地图，该地图可以随著冲突的进展而更新。地图管理员米库拉在接受乌克兰公共广播Suspilne采访时回忆说，曾经问过自己“为什么不在乌克兰建立同样的东西？」。
在2021年—2022年俄乌危机中，该组织逐渐将重点转向针对乌克兰的新闻和分析；报告敌对行动并追踪俄罗斯军事装备和人员在俄乌边境一带的动向，还有国际对危机的反应。全面入侵开始前几个小时，Deep State UA的Telegram频道订阅人数首次突破10,000人。
Deep State UA的Telegram频道因其在俄罗斯入侵乌克兰之初的报道和分析而使到人气大幅上升。该组织及其社区帮助驳斥了在战争初期衍生出的大量谣言，例如俄军马卡洛夫海军上将号巡防舰「被击沉」、乌军的拜拉克塔尔TB2战机被「全数摧毁」。
2024年3月13日，Deep State UA与乌克兰国防部签署合作备忘录，双方将会透过数据交换、以利用最新资讯加强乌军的防御能力。


=== 地图历史 ===

DeepStateMap.Live地图是在俄罗斯全面入侵乌克兰当天（2022年2月24日）建立的，该地图最初是在Google地图提供的「我的地图」服务的基础上建立的。但Google平台在3月底以「违反服务条款」为由将该地图下架、禁用，从而实际上关闭了该网站；虽然该平台没有具体地解释该地图如何「违反」条款，但营运地图的Deep State UA团队认为Google是在收到大量投诉、多次遭到俄国黑客攻击之后，因为不想承担发布此类资讯的责任而决定下架。Deep State UA团队在下架之后的一周之内不断尝试恢复该地图，然而均无功而返，在4月3日之前地图的版本均已遗失。在原地图被下架后，Deep State UA与其中一位新加入的程式设计师于3月27日推出了自主研发、并且沿用至今的地图，并且正式将其命名为「DeepStateMap」。地图最终在4月26日重新向公众开放。
新版本地图推出之后，由于其比Google地图更加独特的界面外观和更好的互动式功能，该地图在乌克兰更受欢迎；到了2022年6月，它已成为该国浏览量前23位的网站。然而在离开Google并且独立托管地图后，伺服器运行成本增加和安全性下降，并且不断遭受网路攻击；最大规模的一次DDoS攻击发生在8月10日，该地图在当天收到来自俄罗斯、中国、巴西、北韩等IP一共1300万项请求，但Deep State UA团队称这些攻击没有造成任何影响。在乌克兰军队在哈尔科夫反攻中夺回伊久姆和利曼两座城市期间，该地图的欢迎程度有所上升，并在30分钟内达到了120,000名访客的峰值，截至当天结束时一共有790万名访客浏览。Deep State UA团队指该地图每天平均约有300万人次浏览量。2022年10月，该地图的浏览量已超过2亿次，使其成为乌克兰最受欢迎的俄乌战争线上地图，也是全球最流行的线上地图之一。
如今，由大约100名志愿者组成的Deep State UA团队由两位创始人领导；由于该组织没有实体办公室，他们利用自己的闲暇时间在家工作并透过Telegram与其他志愿者进行交流。除了他们的地图和Telegram频道外，Deep State UA也在YouTube和推特上进行广播，但由于他们在这些平台上花费的时间较少而没有取得太大的成功。自2022年3月8日起，该组织进行众筹活动以帮助乌克兰及其武装部队，而截至2023年4月22日，该组织已经筹集总计超过300万格里夫纳（81,277美元）的捐款。2024年2月19日，地图网站再次遭到重大DDoS攻击，但在18分钟之后被解决。2024年2月22日，Deep State UA团队宣布该地图自发布以来浏览量已达10亿次。


== 地图特征 ==
DeepStateMap.Live地图提供乌克兰语及英语版本。地图上被标记为深红色的的领土由俄罗斯军队控制（自2022年全面入侵开始占领的领土）；标记为浅蓝色的领土为乌克兰军队在两周之内重夺的领土；标记为绿色的领土是在两周之前被乌军重夺的；标记为紫色的领土则是2014至2022年间被俄罗斯和两个分离主义叛乱政权（顿涅茨克人民共和国和卢甘斯克人民共和国）占领的乌克兰法理领土；在乌克兰以外地区被标为红色的领土被俄罗斯占领（如德涅斯特河沿岸、卡累利阿、车臣共和国和千岛群岛）；对于控制权存在争议、没有来源证实的领土，均一律以灰色标记。被标记为被解放（浅蓝色／绿色）的领土，必须是在此前被俄罗斯长期占领一段时间，仅仅是路过的不会被加入在内。地图的早期版本将俄占区以黑色标记，但此后已变为深红色。
地图的互动功能包括：允许用户切换已知俄军单位和舰队位置的代表图示、以及显示俄军攻势的箭头符号。地图还可以显示俄罗斯在乌克兰控制的主要铁路线，以及乌克兰境内外的俄占指挥部和机场，而且也提供测量工具功能。通过屏幕左侧的按钮，用户可以检视乌克兰及其周边地区的天气图、整个乌克兰的背景辐射、俄罗斯的战壕网络、过去48小时内俄罗斯和乌克兰的核武数量、各式火砲的射程模拟、以及俄罗斯境内不明原因火灾的地点。DeepStateMap.Live地图在以前曾经有一个名叫「病原体」的功能，该功能允许用户查看俄军在乌克兰被空拍的模糊图像。


=== 行动应用 ===
Deep State UA于2023年3月2日在Google Play平台推出第一版的DeepStateMap行动应用程式，上架仅2天即有一万人次下载。尽管在Apple公司提出反对意见、认为该地图是有意歧视俄罗斯人的情况下，DeepStateMap的IOS版本还是在约两个月后的4月29日被推出。有开发人员警告用户Google Play平台上存在虚假程式版本，而Deep State UA团队也提醒正版的DeepStateMap.Live应用程式不会存在广告。


== 地图来源 ==
根据地图管理员波霍利的说法，用于制作、更新地图的来源包括—社交媒体上发布的照片和影片证据、身处于战争前线上的Telegram频道追踪者、俄占区乌克兰平民、以及负责确认资讯的乌克兰军方；对于仅自称在该前线地区的人提供的消息，如果没有视觉证据或乌克兰武装部队总参谋部的确认，则会等到有类似的报告出现时，方会予以更新。而该团队考虑到来自俄罗斯的来源普遍存在政治宣传、假消息的情况，因此拒绝使用俄罗斯的消息来源。在Deep State UA团队的大约100名志愿者中，有60名负责事实查核。


=== 实际情况 ===
作为一个资讯更新稍有延迟、有时候不准确的开源情报网站，Deep State UA警告在规划疏散路线、战斗区域或进行其他敏感和具体的军事行动时不要使用该地图。而且Deep State UA团队在更新乌克兰反攻的进度时，也有意地推迟地图的更新，避免敌军能及时反应、影响乌克兰军队的推进，但有时地图更新过快还是引起一些乌克兰士兵的不满。原本该地图有意禁止来自俄罗斯的IP访问，但该计划不了了之；一名志愿者称其原因是有俄罗斯士兵利用DeepStateMap地图向乌军投降。米库拉称乌克兰军方赞扬了地图在显示前线状况方面的平衡性，「不会急于说太多了，但也不至于落后太远」。
