## Findings

1. **Wiki not suitable as primary IME corpus** — freq distribution
   skews toward proper nouns + historical/political content, missing
   the casual conversational vocabulary that drives real IME usage.
2. **Pipeline missing the merge step** — `tools/dict-pipeline/run.sh`
   only emits diff reports; the vNEXT `.idf` rebuild step uses the
   unchanged shipped weights.tsv, so wiki freq never actually flows
   into the dict. To ship a new dict you'd need a `pinyin-build-
   weights` invocation with wiki added as a corpus source (which is
   a 1-2 day refactor of `core/crates/inputx-pinyin/tools/build_
   weights.rs`).
3. **Audit value is in gap-identification, not bulk replacement** —
   the diff is most useful for spot-checking specific missing
   entries (wubi dict has no `不是` / `二次` / `第一次`!) than for a
   wholesale corpus blend.

   - `ti`:  提 → **体** (subtitles use 身体)
   - `xi`:  西 → **喜** (subtitles use 喜欢)
   - `zhi`: 只 → **知** (subtitles use 知道)
2. **Wubi rare-Jianma2 yield re-broken**: `mo`→嶙 / `cu`→骈 climb
   back to #0 because their raw_freq baseline shifted under OPUS
   mix (rare Jianma2 simcodes pick up minor count contributions).

4. **Viterbi `中国人` displaced**: long-phrase entries (`中国人民大学`
   etc.) outrank the 3-char `中国人` because OPUS provides bigger
