# Python deps for inputx eval harness + Phase 2 LM training.
#
# IMPORTANT — Python version constraint
# -------------------------------------
# Use Python 3.12.x  (`brew install python@3.12`).
# Do NOT use Python 3.14+: several deps below ship pre-compiled wheels
# that have not been updated to the strict CPython 3.14 ABI / numpy 2 /
# re._parser / pickle._batch_setitems changes. Specifically (logged
# 2026-06-15 during Phase 2 CP-2.2):
#   - wikiextractor 3.0.6 → re._parser global-flag rejection
#   - kenlm pip      → _PyLong_AsByteArray API signature change
#   - fasttext-wheel → numpy 2 strict copy=False rejection
#   - dill (used by datasets) → pickle._batch_setitems signature change
# Phase 2 climb-plan errata documents the full trap list.
#
# Rebuild .venv if the python interpreter is wrong:
#   /opt/homebrew/opt/python@3.12/bin/python3.12 -m venv tools/eval/.venv
#   tools/eval/.venv/bin/pip install --upgrade pip
#   tools/eval/.venv/bin/pip install -r tools/eval/requirements.txt
#
# Phase 2 CP-2.3 prerequisites: brew install boost eigen (for kenlm).
# brew has NO `kenlm` formula — use pip kenlm + the brew C++ deps.
